# 마지막 하교 — 목적과 범위

## 목적
야간 학교에서 인형의 접근을 살피고 교실 문으로 막으며 살아남는 생존 공포게임을 만든다. 사용자가 채택한 방향은 ‘확인→접근 징조→문 닫기→생존 또는 게임 오버’다.

## 현재 범위
- HTML/CSS/JavaScript와 Three.js 브라우저 게임. Canvas는 호환 화면이다.
- 토끼 1종 공격자, 기존 학교 복도·교실·가구·다른 인형 이미지 유지.
- 60초 생존하면 탈출. 6초 접근 경고 뒤 교실의 닫힌 문으로 공격을 막는다. 문은 7초 유지·3초 회복.
- 실패하면 토끼가 눈앞에 나타나고 게임 오버. 승리/패배 후 재시작한다.
- 화살표/WASD 이동·회전, E 교실 입장/문 조작, M 음소거, Escape 처음 화면.
- 음소거에서도 위치·이빨 표정·경고 문구로 대응할 수 있다.
- 기존 계단 정답 판정과 무작위 이상현상은 일반 플레이에서 사용하지 않는다. 관련 모듈·회귀 테스트는 이전 작업 참고용으로 보존한다.

## 후속 범위
학생 인형·창밖 귀신의 공격 규칙, 불규칙한 접근·관찰에 반응하는 AI, 추가 맵은 별도 명세로 정한다. 기존 캐릭터 추가 이미지 제작 중단은 유지한다.
