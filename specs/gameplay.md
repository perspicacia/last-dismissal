# 현재 기본 게임

사용자 채택에 따라 일반 게임은 [rabbit-survival.md](rabbit-survival.md)의 토끼 생존 흐름을 따른다. 아래 계단 규칙은 이전 관찰 버전의 기록이며 현재 일반 게임의 완료 조건이 아니다.

# 기본 게임 요구사항과 완료 조건

현재 구현을 기준으로 작성한 명세다. 아래 완료 조건은 검증 항목이며, 작성 자체가 모든 항목의 재검증을 뜻하지 않는다.

## 요구사항

- 시작과 재시작은 정상 연습 복도, 진행 0에서 시작한다.
- ↑↓/WS는 전후 이동, ←→/AD는 회전이다. 벽과 복도 경계 밖으로 이동하지 않는다.
- 4.6m 미만에 있고 바라보는 사물만 E 또는 조사 버튼으로 조사한다.
- 복도 끝 z≥24의 왼쪽/오른쪽 계단 입구로 직접 걸어 들어가면 전환된다. 가운데에서는 전환하지 않는다. 연습에서는 아래층만 가능하고, 정규 복도에서는 물건 수집이나 교실 방문 없이 진행한다. 상세 조건은 `walk-through-exits.md`를 따른다.
- 정답은 진행을 1 늘리고, 오답은 0으로 되돌린다. 연습 선택은 진행에 포함하지 않는다. 5회 연속 정답이면 엔딩을 표시한다.
- 토끼 이상현상에서 토끼를 4.2m 미만 거리에서 바라보면 이빨 표정으로 바뀐다. 해당 복도에서는 유지하고 다음 복도에서 초기화한다.
- BGM은 게임 시작 또는 ‘소리 확인’ 클릭 후 재생한다. 음소거해도 이상 판정 단서는 남는다.

## 완료 조건과 검증

1. `npm test`가 통과한다. 판정 변경은 `tests/logic.test.js`, 이동·조사·표정 조건 변경은 `tests/movement.test.js`의 관련 검증을 확인한다.
2. 브라우저에서 시작 → 이동·회전 → 조사 → 계단 선택 → 정답/오답 → 탈출 → 재시작을 확인한다.
3. 토끼의 정상·이빨 표정과 새 복도 초기화를 확인한다.
4. 소리 확인·음량·음소거를 확인하며, 오디오 신호 확인과 실제 청취 확인을 구분한다.
5. 실제 수행한 항목과 수행하지 않은 항목을 `docs/progress.md`와 완료 보고에 기록한다.
