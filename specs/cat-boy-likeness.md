# 고양이 모델 참고·음악실 남자아이 원본 외형 일치

> 남자아이의 얕은 앞면 규칙은 [piano-boy-depth-repair.md](piano-boy-depth-repair.md)로 갱신됐다. 원본 보존/비공격/로딩 규칙과 고양이 규칙은 유지한다.

2026-10-06, Issue #97. 사용자 요청: 첨부한 Hum3D/3DModels.org 검은 고양이 모델의 외형을 참고해 수정하고, 음악실 남자아이가 첫 화면 원본과 다르게 보이는 이유를 설명하고 보완한다.

- 고양이는 첨부 이미지의 둥근 몸통/엉덩이, 자연스럽게 이어진 가슴·목, 작은 얼굴과 넓은 삼각 귀, 금빛 눈·짧은 주둥이·수염, 위로 선 긴 꼬리를 코드 기반 3D 모델에 반영한다. 상용 모델 파일 다운로드/구매나 원본 자산 복제는 하지 않는다.
- 목/몸을 하나의 곡면으로 잇고 다리 표면은 기존 두 관절을 따라 연속적으로 변형한다. 짧은 털 메시의 꼬리 변형도 공유한다. 기존 3초 등장·안전 경로·접지 보행·무작위 간격·음향·동작 줄이기/종료 정리는 유지한다. 꼬리 높이를 포함한 체형은 통로의 기존 수평 여유를 지킨다. Canvas 실루엣도 같은 몸/꼬리 비율을 따른다.
- 음악실 남자아이의 기준은 첫 화면과 같은 `assets/piano-boy-ghost.png`다. 원본 PNG를 보존하고 얼굴/머리/티셔츠·반바지/맨발의 사진 위치·비율에 맞게 앞면 곡면과 닫힌 뒤 볼륨을 조정한다. 구형 부품 사이의 사진 누락·과도한 정면 굴곡을 줄인다. 사진에 없는 옆/뒤는 근사이며 완전한 전 방향 복원이라고 보고하지 않는다.
- 음악실 좌석/발 접촉·위치/방향·정적 분위기 요소·로딩 대기/실패·모델 재사용을 유지한다. 토끼만 공격하고 학교 톤·음향·조작·판정은 보존한다. 다른 기존 캐릭터 외형은 변경하지 않는다.
- 개발용 밝은 비교 화면에서 원본과 모델의 정면·사선·측면을 확인한다. 일반 게임에서는 음악실/고양이를 새 조명에서 확인한다. 원본과 같은 모델을 만드는 데 필요한 실제 조형·UV/재질·측면/후면 자료와, 고양이 골격/보행 애니메이션 자산의 역할을 설명한다.
