# 근거리 계단 투영 보정

- 입구 가까이에서 일부 꼭짓점이 카메라 뒤로 넘어가도 계단 전체를 생략하지 않는다.
- 계단 클립 영역·면·난간 선분을 카메라 앞 평면에서 잘라 보이는 부분만 투영한다.
- 사용자 첨부와 유사한 입구 근거리·비스듬한 시점, 좌우 계단 근거리 회전을 개발 비교 화면에 추가한다.
- 쇠창살 제거와 기존 이동/계단 진행 규칙은 유지한다.
- 검증: 근거리 평면 교차 다각형·선분 회귀 테스트, npm test, JS 구문 검사, git diff --check. 실제 브라우저 근거리 재현·회전·계단 전환·재시작 확인.
