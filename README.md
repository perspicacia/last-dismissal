# 마지막 하교

부트캠프 과제용 관찰 공포게임. 목표는 짧은 플레이로 규칙과 분위기를 전달하는 것이다.

## 실행

프로젝트 폴더에서 `npm start` 또는 `python3 -m http.server 8080 --bind 127.0.0.1`을 실행하고 브라우저에서 http://127.0.0.1:8080 을 연다. 브라우저 실행에는 저장소의 `vendor/` 모듈을 사용하므로 CDN 연결이나 패키지 설치가 필요 없다. 의존성을 재설치할 때는 `npm ci`를 실행한다. HTML 파일을 직접 열면 ES 모듈 제한 때문에 실행되지 않을 수 있으므로 로컬 서버를 사용한다.

- 일반 플레이: 무작위 정상/이상 복도. 직접 걸어가 가까운 사물을 조사한다.
- ↑↓는 앞뒤 이동, ←→는 방향 회전. WASD도 같은 방식으로 조작할 수 있다. 누르고 있으면 연속 이동한다.
- 첫 연습 복도에서는 정상 모습을 기억하고 아래층으로 걸어 내려간다. 열쇠·확인표 수집과 문 해금은 필요 없다.
- E는 바라보는 가까운 사물 조사. 플레이 화면에는 이동 버튼과 키 안내가 없다. 조작 설명은 시작 화면에서 확인한다. Esc로 시작 화면에 돌아갈 수 있다. 현재 이동은 키보드가 필요하다.
- 복도 끝 왼쪽(↑)/오른쪽(↓) 입구로 직접 걸어 들어가면 다음 복도로 넘어간다. 중앙에서는 전환하지 않는다. 첫 연습에서는 위층이 닫혀 있다.
- 연습 다음부터 왼쪽 5m 교실문에서 **교실 들어가기** 또는 E로 3-2 교실을 자유롭게 탐색할 수 있다. **복도로 돌아가기**는 입장 전 위치를 복원한다. 교실 방문은 선택 사항이다.
- 음량 슬라이더에 포커스가 있으면 화살표는 음량을 조절한다. 복도 화면을 클릭하면 이동 조작으로 돌아온다.
- `npm test`: 정답 누적, 오답 초기화, 무작위 현상 선택, 이동·충돌·조사 거리, 토끼 표정 전환 조건을 검사한다.

## 파일 구성

`index.html`은 화면, `style.css`는 화면 스타일, `logic.js`는 판정과 현상 선택, `game.js`는 조사와 화면 상태, `audio.js`는 합성 음향, `movement.js`는 이동·충돌·조사 거리, `window-view.js`는 창밖 숲·가로등·귀신 풍경, `corridor.js`는 이동·렌더 연결을 담당한다. 기본 게임은 `three-school.js`의 Three.js 실내 렌더와 `three-outdoors.js`의 실제 3D 외부 풍경을 사용한다. 기존 Canvas 렌더는 비교 화면 및 WebGL 초기화 실패 시 호환 화면으로 유지한다. 현상을 늘릴 때 `logic.js`의 목록, `game.js`의 조사 문구, `corridor.js`의 그림 상태를 함께 수정한다.

## 첫 버전 기획

- 배경: 야간 학교 복도. 과제를 끝낸 학생이 같은 복도에 갇힌다.
- 기본 규칙: 이상이 있으면 올라가고, 없으면 내려간다.
- 첫 복도는 정상 상태를 익히는 연습 공간이다.
- 정답 5회 연속으로 하교. 오답은 진행을 0으로 되돌린다.
- 이상현상은 한 번에 하나만 나온다. 애매한 장식 변화는 판정에 쓰지 않는다.
- 정상 복도에도 약한 환경음이 있다. 음악 자체는 정답 힌트가 되지 않는다.
- 시작 버튼과 재시작 버튼은 모두 무작위 일반 플레이로 진입한다.

## 음향 기획

큰 소리로 놀라게 하기보다, 익숙한 공간이 낯설어지는 분위기를 만든다.

1. 시작 화면: 무음. 사용자가 시작 버튼을 누른 뒤에만 오디오를 켠다.
2. 복도: 낮은 드론과 형광등 소리. 드론은 작게 유지하고 장시간 들어도 부담이 적도록 한다.
3. 조사: 필요한 사물에 접근하거나 조사할 때 짧은 소리. 시각적인 단서도 함께 제공한다.
4. 계단 선택: 짧은 전환음. 오답은 불협화음, 정답은 작은 종소리.
5. 탈출: 긴장음을 낮추고 새벽 분위기의 화음을 낸다.

초기 버전은 Web Audio로 직접 합성한 음향을 사용한다. 외부 음악 파일이나 다운로드가 필요하지 않다. 이후 실제 음원으로 교체할 때 출처와 이용 조건을 기록한다. 음소거와 음량 조절을 제공하고, 소리가 없어도 판정 가능하도록 설계한다.

노트북 스피커에서도 들리도록 196~349Hz의 드론과 24초 반복 선율을 함께 사용한다. 기본 음량은 50%다. 상단의 ‘소리 확인’은 오디오를 다시 시작하고 확인용 종소리를 재생한다. 시작 전에는 음악이 재생되지 않으며, ‘소리 확인’을 누르면 시작 화면에서도 들을 수 있다. ‘BGM 재생 중’은 브라우저의 오디오 실행 상태를 뜻하며, 기기나 브라우저 자체의 음소거 여부까지 확인하지는 않는다.

## 범위와 이후 개선

현재 버전은 화살표로 걷고 둘러보는 1인칭 복도 탐색 게임이다. 벽을 통과하지 못하며 가까이에서 바라보는 사물만 조사할 수 있다. Three.js로 학교 실내와 창밖 공간을 표현한다. 창밖 나무·가로등·운동장은 실제 거리별로 배치하며 조명과 그림자를 사용한다. 적 AI와 추가 맵은 후속 범위다. 후속 개선에서는 새 기능을 추가하기 전에 플레이어가 정상 상태와 이상 상태를 구별할 수 있는지 확인한다.

## 토끼의 두 얼굴

정상 토끼는 입을 닫은 모습이다. 토끼 이상현상에서는 복도 중간으로 옮겨진 토끼를 4.2m 안에서 바라보면 날카로운 이빨을 드러낸다. 한 번 드러낸 얼굴은 해당 복도가 끝날 때까지 유지되고, 새 복도에서는 초기화된다. 두 장의 투명 PNG를 교체하는 연출이며, 턱이 연속적으로 움직이는 3D 애니메이션은 아니다.

창밖 정상 풍경은 숲과 가로등이다. 창문 이상현상에서는 검은 머리의 도자기 귀신이 앞쪽 창 밖에 나타난다. 개발용 렌더 비교는 서버 실행 후 `http://127.0.0.1:8080/tests/fixtures/window-review.html`에서 확인한다. 플레이 화면에 시연 버튼은 추가하지 않았다.

시계·창틀·문틀·게시판·형광등의 깊이는 `clock.js`와 `scene-depth.js`에서 세계 좌표로 투영한다. 창밖 숲은 거리별 시차를 사용한다. 시계 정상/이상 및 창틀 비교 화면: `http://127.0.0.1:8080/tests/fixtures/depth-review.html`.

## 3D 화면과 검증

- Three.js 0.186.1 (MIT). `package-lock.json` 버전을 고정하고 배포 모듈·라이선스를 `vendor/`에 보관한다. 라이브러리 갱신 시 `npm ci` 후 `node_modules/three/build/three.module.js`, `three.core.js` 및 LICENSE를 vendor에 동기화한다.
- WebGL2 지원 브라우저가 필요하다. 3D 초기화 실패 시 기존 Canvas 화면으로 전환하며 시작 화면에 호환 화면 안내를 표시한다. 모바일 성능은 별도 확인이 필요하다.
- 토끼와 창밖 귀신은 기존 투명 이미지의 빌보드다. 공간·가구·나무·계단의 3D 전환과 캐릭터 모델링 완료를 구분한다.
- 3D 정상/이상 비교: `http://127.0.0.1:8080/tests/fixtures/three-review.html`. 이 개발용 화면의 버튼은 일반 게임에 표시되지 않는다.
- 시작·5회 선택·엔딩 검증: `http://127.0.0.1:8080/tests/fixtures/three-flow.html`. 실제 게임 UI/컨트롤러를 사용하되 검증 페이지에서만 무작위를 정상 복도로 고정한다.

교실 금발 인형: 평소에는 바닥에 누워 있다. 교실 문 손자국이 나타난 이상 구간에서 가까이 다가가 잠깐 바라보면 일어나 무서운 표정으로 바뀐다. [상세 조건](specs/classroom-doll.md).
