# 마우스 시점과 편안한 이동 (Issue #80)

좌우/상하 감도 분리·상하 고정·대체 키보드와 설정 저장은 [최신 시점 접근성 명세](accessible-camera-controls.md)를 따른다. 아래 단일 감도 규칙은 이전 구현 기록이다.

사용자가 WASD 이동·마우스 시점 제안을 채택했고 현재 조작이 어지럽다고 알려 주었다.

- 일반 게임에서 W/S는 전후 이동, A/D는 옆걸음이다. 대각선 이동 속도는 직선과 같다. 기본 보행은 3m/s, 화살표 좌우 회전은 1.05rad/s다. 기존 개발용 비교의 자동 시점은 보존한다.
- 마우스는 좌우/상하 시점을 움직인다. 기본 감도 65%, 일시정지에서 20~180%로 조절한다. 상하 시점은 약 ±60도로 제한한다. 걷는 중 카메라 흔들림·소품 응시·계단 자동 기울임은 일반 게임에서 사용하지 않는다.
- 시작/계속 버튼의 사용자 클릭으로 Pointer Lock을 요청한다. 지원하지 않거나 거절하면 캔버스를 드래그하거나 화살표로 둘러볼 수 있다. 좌우 화살표 회전과 위아래 이동은 계속 지원한다.
- E 또는 잠긴 화면의 클릭으로 가까운 문을 이용한다. 드래그가 문 클릭으로 오인되지 않아야 한다. 기존 입장/복귀 버튼도 유지한다.
- Esc, 일시정지 버튼, 포커스 이탈, Pointer Lock 해제는 현재 탐색을 일시정지하고 커서를 돌려준다. 위치·방문 기록·토끼 배치는 유지하며 이동·판정·효과음은 멈춘다. 계속 버튼으로 재개하고 처음 화면 버튼으로 초기화한다. 이 규칙이 기존 Esc 초기화 규칙을 대체한다.
- 토끼 발견은 기존 거리/수평 응시와 수직 응시를 함께 확인한다. 천장/바닥을 보는 동안 화면 밖의 토끼를 발견하지 않는다. 발견 후 공격 연출은 시점 중앙으로 접근하고 기존 이미지 비율과 종료/재시작을 유지한다.
- 감도 값은 같은 페이지의 재시작에도 유지한다. 일시정지 창은 키보드 포커스를 가두고 닫을 때 게임으로 돌려준다. 추가 조작 안내는 일시정지 창에 둔다.
- 트랙패드와 OS 영역 캡처의 충돌 보완은 [capture-cursor-release.md](capture-cursor-release.md)를 따른다. P/캡처 버튼은 메뉴 없는 화면 고정과 커서 해제, 수식키 입력 보호를 제공한다. 캡처 도구로 포커스가 옮겨져도 고정을 유지하고 명시적으로 재개한다.

## 완료 조건

입력·대각선/옆걸음·충돌·마우스 감도/각도·잠금 실패/늦은 요청/해제·수직 응시의 자동 테스트를 실행한다. 실제 브라우저에서 이동·마우스 또는 드래그·일시정지/재개·종료/재시작을 확인한다. 지원 환경별 Pointer Lock 확인 여부와 플레이어의 어지러움 체감이 아직 검증되지 않았다는 점을 구분해 기록한다.
