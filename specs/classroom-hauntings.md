# 교실 공포 연출과 인형 왜곡 수정

## 사용자 요청 범위
- 학생 인형 사진을 머리카락/목/팔다리 측면에 길게 늘이는 볼륨 방식을 제거한다. 얼굴과 의상 비율을 유지하고, 안정적인 사진 표면과 별도 깊이 형상으로 입체감을 만든다. 기존 자산을 사용하며 새 캐릭터 이미지는 제작하지 않는다.
- 3-1 창밖 운동장에 주인 없는 농구공이 통통 튄다. 창쪽을 응시할 때만 움직이고 시선을 돌리면 멈춘다. 동작 줄이기에서는 공이 멈춘 상태로 보인다.
- 3-2 교실 뒤 오른쪽 구석에 웅크린 그림자/기존 인형 계열의 정적 공포 요소를 배치한다. 중앙 통로와 복귀를 방해하지 않는다.
- 3-3·무용실 창밖 긴 머리 귀신은 창가 가까이 접근하여 바라보면 입꼬리가 비정상적으로 올라간 미소와 작은 고개 기울임을 보인다. 이 이벤트는 공격/패배를 일으키지 않는다. 멀어지면 기본 표정으로 돌아가며 재시작 초기화.
- 교실 입장 1회당 미닫이문 드르륵 효과음 1회. 교실 체류 중 12~22초 간격으로 짧고 먼 아기 울음이 낮은 음량으로 들린다. 방 밖/게임 오버/시작 화면에서는 중지하고 재시작 초기화.
- 토끼 효과음은 낮은 성대·거친 배음·포효 계열로 교체하되 음량만 올리지 않는다. 이빨 시점 단발 재생·전체 음량·음소거·정리를 유지한다.
- 시각 공포 연출과 패배 판정은 소리가 없어도 동작한다. 토끼 무작위 배치/발견 패배 규칙은 유지한다.

## 분담과 완료 조건
인형 담당: doll-volume.js 및 관련 테스트. 음향 담당: audio.js, sound-effects.js, 울음 스케줄 순수 모듈/테스트. 공포 환경 담당: 독립 room-hauntings.js/테스트. 통합 담당: three-school.js·game.js·corridor.js·Canvas 연결과 문서. 각 담당은 별도 워크트리에서 작업하며 공통 파일 변경은 통합 담당만 수행한다.

npm test와 git diff --check 통과. 브라우저에서 인형 바닥/책상·창밖 공·구석·귀신 미소·문 입장 효과음 호출·게임 오버/재시작을 확인한다. 합성 음향의 실제 음색과 체감 강도는 미리 듣기 파일과 플레이로 사용자가 판단한다.
