# 입체 학교 계단

- 복도 끝의 왼쪽 위층/오른쪽 아래층 계단을 실제 높이와 깊이를 가진 Canvas 원근 투영으로 그린다.
- 참고 사진처럼 회색 석재 계단판·단의 앞면·검은 미끄럼 방지선·금속 기둥과 경사진 손잡이를 표현한다. 아래층에는 아래로 꺼지는 계단실 벽과 어두운 바닥을 넣는다.
- 새 선택 버튼이나 문구는 추가하지 않는다. 기존 계단 방향 화살표와 첫 연습 위층 차단은 유지한다.
- 진행 판정 위치와 좌우 구분·정답 규칙은 기존 walk-exits.js를 유지한다. 계단 진입은 다음 구간으로 전환되며 개별 계단을 걷는 물리 시뮬레이션은 범위 밖이다.
- 검증: npm test, 변경 JS 구문 검사, git diff --check. 브라우저 원거리/근거리에서 상승·하강과 난간 가림, 정상 아래층 전환 및 재시작을 확인한다.
