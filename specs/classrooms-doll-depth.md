# 교실 추가와 학생 인형 입체감 (Issue #50)

- 기존 3-2, 음악실, 무용실에 3-1/3-3 교실을 추가한다. 다섯 문을 구분하고 입장·복귀·방문 기록·토끼 무작위 배치 범위를 모두 다섯 방으로 맞춘다.
- 복도 문: 3-1 z3, 3-2 z7, 3-3 z11, 음악실 z16, 무용실 z21. 가까운 문 중 가장 가까운 곳을 선택한다. 기존 비교/회귀 코드의 단일 CLASSROOM_DOOR는 이전 규칙으로 보존한다.
- 3-1은 가지런한 책상·창가 책상 위 학생 인형, 3-2는 기존 누운 인형·가구, 3-3은 어긋난 책상과 창밖 귀신을 배치한다. 음악실에는 악기 주변에 학생 인형, 무용실에는 창밖 귀신을 더한다. 분위기 인형·귀신은 정적이며 공격·즉시 종료를 일으키지 않는다.
- 누운 학생 인형 머리·몸통·치마·팔다리에 실제 깊이와 접촉 그림자를 더한다. 얼굴 사진을 심하게 굽히거나 측면을 길게 늘리지 않는다. 기존 이미지·표정·비율을 유지하며 새로운 이미지 파일은 제작하지 않는다.
- 모든 방의 중앙 탐색 동선을 확보한다. 기존 토끼의 표정·팔·비명·게임 오버 판정은 유지한다.

## 검증
`npm test`, `git diff --check`. 5방 입장·무작위 배치·방문·충돌과 인형 깊이/얼굴/실루엣 회귀를 확인한다. 브라우저에서 새 교실·분위기 귀신·누운 인형을 다른 각도로 확인하고 시작→탐색→발견→게임 오버→재시작을 확인한다.

가까이서 정적 학생 인형을 바라볼 때도 카메라 시선을 낮춘다. 이미지 기반 볼륨이므로 낮은 측면에서 머리카락 질감의 늘어짐은 남으며, 완전한 3D 모델 제작은 이번 범위에 포함하지 않는다.
