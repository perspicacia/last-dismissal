# 사실적인 분필 글씨 (Issue #78)

2026-10-04 사용자 요청: 첨부한 칠판 사진처럼 손으로 쓴 한글과 분필 가루/끊긴 획을 표현한다.

- 3-1·3-2·3-3의 기존 반 이름·날짜·오늘의 당번·가상 이름·정리 문구는 유지하고, 한글 손글씨 서체와 농담/작은 획 끊김/분필 입자를 사용한다. 글씨의 윤곽을 알아보기 어렵게 훼손하지 않는다.
- 판에는 미세한 표면 질감과 넓고 부드러운 지우개 자국을 더한다. 큰 반복 가로 줄무늬를 피하고 글씨가 새겨진 인쇄물처럼 보이지 않도록 한다.
- 공식 출처의 OFL 한글 서체를 로컬 자산과 라이선스로 보관한다. 게임 실행 중 외부 폰트/CDN에 접근하지 않는다. 로딩 실패 시 시스템 서체로 칠판을 표시하고 플레이를 유지한다.
- 코드 기반 Canvas 질감을 Three.js와 Canvas 호환 화면에서 공유한다. 질감은 방별 고정 난수로 한 번 생성/재사용하며 게임 난수·프레임마다 재생성·공포 이벤트/충돌 판정을 바꾸지 않는다. 기존 칠판 크기/프레임/분필/지우개와 캐릭터 PNG는 보존한다.
- `npm test`, `git diff --check`; 실제 브라우저의 전체 칠판과 근접 글씨, 세 교실의 문구·방향/로딩, Canvas 호환을 확인한다. 실제 모바일 기기/서체 실패 화면을 직접 재현하지 않았다면 미확인으로 기록한다.
