# 첫 열쇠 구간 — 디자인 방향

기준: [게임 목적](PRD.md), [기본 게임 명세](../specs/gameplay.md), [기존 캐릭터](../CHARACTERS.md). 사용자가 승인한 기존 인형과 어울리는 방향 및 열쇠 하나·문 하나 구간만 다룬다. 세부 색상·연출은 초기 제안이며 사용자 피드백으로 보완한다.

## 컨셉과 배치

학교 축제의 인형 전시가 남아 있는 야간 복도. 낡은 나무 책상과 아이보리 안내 쪽지로 학교의 생활감을 유지하고, 민트색 토끼와 남색 교복 인형이 어울리는 차분한 배경을 사용한다. 새 이미지·새 캐릭터를 만들지 않는다. 학생 인형은 현재 이미지 단계이며 게임 연결은 별도 작업이다.

```text
                    기존 관찰 복도 / 계단
                             ↑
    왼쪽 벽       [방화문: 입구에서 약 8m]       오른쪽 벽
                  복도 전체를 가로막음       안내 쪽지
                             ↑
                                             [당직 책상]
                  입구에서 약 4m              열쇠
                             ↑
                        [시작 / 입구]
```

- 열쇠 책상은 오른쪽 벽에 붙이고 중앙 이동 경로를 비운다. 시작 시 열쇠가 시야에 들어오도록 크기와 밝기를 확보한다.
- 방화문은 책상 뒤에 배치한다. 기존 교실 문과 구분되도록 `야간 통행 방화문` 표찰을 붙인다.
- 4m·8m는 입구 기준 기획 거리다. 실제 플레이어 시작 좌표와 충돌 좌표는 개발 명세에서 확정하며, 기존 오른쪽 창문과 책상이 겹치지 않게 배치한다.
- 첫 연습에서만 획득·잠금 해제한다. 이후 반복 복도에서는 열쇠 수집을 다시 요구하지 않는다. 재시작은 연습 구간부터 시작한다.

## 쉬운 조작과 화면 피드백

| 상태 | 표시 문구 | 동작 |
| --- | --- | --- |
| 열쇠 획득 전 | `오른쪽 당직 책상에서 열쇠를 찾으세요` | 목표를 상시 표시 |
| 열쇠 근처 | `E · 열쇠 줍기` + `열쇠 줍기` 버튼 | E 또는 버튼 한 번으로 획득. 작은 열쇠를 정확히 조준할 필요 없음 |
| 획득 후 | `통행 열쇠 보유 · 방화문으로 이동` | 책상 위 열쇠 제거, 보유 표시 유지 |
| 열쇠 없이 문 접근 | `잠겨 있다 · 오른쪽 당직 책상을 확인하세요` | 다음 행동 안내. 실패 횟수·시간 제한 없음 |
| 열쇠를 갖고 문 접근 | `E · 문 열기` + `문 열기` 버튼 | 잠금 해제와 개방을 한 번에 수행 |
| 문 열린 뒤 | `문이 열렸다 · 앞으로 이동하세요` | 통과 가능 상태를 글자와 문 모양으로 표시 |

상호작용은 기존 이동 키를 유지한다. 열쇠와 방화문은 가까이 접근하는 것으로 대상 선택이 가능하게 하고, 기존 이상현상 조사는 기존 규칙을 유지한다. 화면 버튼은 하단에 고정하고 44px 이상으로 만든다. 키보드 포커스 테두리를 유지하며 버튼 클릭 뒤 화살표 이동이 자연스럽게 이어지는지 확인한다. 안내는 색·음향에만 의존하지 않는다.

## 색상과 초기 공포 강도

| 용도 | 제안 색 | 적용 |
| --- | --- | --- |
| 배경 / 안내 패널 | `#0b110f` / `#131d18` | 기존 UI 유지 |
| 본문 | `#e2e8d9` | 어두운 배경에서도 읽히는 안내 |
| 상호작용 | `#b9d7c7` | 토끼의 민트색과 연결, 열쇠·버튼 강조 |
| 소품 | `#ded5b7` | 낡은 열쇠 표찰과 쪽지 |
| 잠금 상태 | `#e7b88e` | 경고 문구와 함께 표시 |
| 맵의 보조색 | `#283340` | 학생 인형 남색 교복과 연결, 필수 안내에는 사용하지 않음 |

첫 구간은 조작을 익히는 시간이므로 점프스케어·이빨 표정 발동을 추가하지 않는다. 낮은 환경음과 짧은 열쇠·문 효과음만 사용하고, 열쇠 획득 때 화면을 암전시키거나 이동을 차단하지 않는다. 기존 관찰 복도에서 토끼 공포 연출을 유지한다. 학생 인형의 등장·표정 전환은 후속 명세로 정한다.

## 개발 전달·확인 항목

- A: 가까이 가기 → E 또는 버튼 → 획득/열기라는 동일한 조작을 구현한다. 열쇠, 문, 목표 안내, 보유 상태를 담당한다.
- B: 획득·문 개방 이벤트에서 짧은 효과음을 재생한다. 별도 위협 이벤트가 정상/이상 판정 규칙에 혼선을 주지 않게 한다.
- 검토: E·클릭 각각으로 완료, 문 먼저 접근했을 때 회복, 음소거 상태에서 완료, 문 통과, 재시작 초기화를 확인한다.
- 디자인 확인: 열쇠 발견성, 현재 목표 이해, 안내 가독성과 기존 캐릭터의 어울림은 실제 브라우저에서 별도로 확인한다. 이 문서는 그 검증을 완료했다는 뜻이 아니다.
