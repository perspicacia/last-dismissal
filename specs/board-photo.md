# 게시판 단체사진 교체

최신 일반 탐색 게임의 낡은 검은 얼굴 사진은 [낡은 게시판 사진 명세](aged-erased-photo.md)를 따른다. 아래 정상/이상 구분은 이전 관찰 모드의 기준이다.

- 기존 도형 학생 그림을 가상의 한국 학생들이 학교 밖에서 촬영한 실사 느낌의 단체사진으로 교체한다.
- 정상 사진에는 학생들이 카메라를 바라보는 자연스러운 얼굴이 보인다.
- 게시판 이상현상은 같은 사진의 얼굴만 검게 지워진 상태로 표현한다. 기존 게시판 위치, 조사 문구, 판정은 유지한다.
- 이미지 로딩 완료 시 현재 복도의 텍스처를 갱신한다. 로딩 지연이 이동과 퍼즐을 막지 않는다.
- 검증: 전체 테스트·구문·공백 검사, 브라우저에서 정상 게시판 확인. 이상 사진의 구성과 얼굴 삭제를 시각 확인한다.
