# 학생 인형 원본 외형 우선 (Issue #64)

사용자는 새 3D 모델이 기존 모습과 너무 달라 원래 느낌을 유지하길 요청했다. 이 명세는 `student-doll-glb.md`의 일반 게임 기본 적용 규칙을 대체한다.

- 기존 `assets/doll-student-concept.png`의 도자기 얼굴·호박색 유리 눈·컬이 있는 금발 단발·남색 세일러복·크림 리본과 전체 비율을 확정된 외형 기준으로 사용한다.
- 일반 게임과 기본 교실 비교 화면은 기존 PNG 기반 2.5D 인형으로 복구한다. 기존 배치·접촉 그림자·이미지 로딩 보완을 유지한다.
- 단순 GLB 시안은 보존하되 자동 로딩/기본 대체를 하지 않는다. 개발용 교실 비교에서 `?model=glb`를 명시하면 시안을 비교할 수 있다. GLB 자산 검증 화면과 재생성 소스도 보존한다.
- 현재 2.5D 표현의 낮은 측면/후면 한계는 남는다. 원본 모습 복구와 찌그러짐의 완전한 3D 해결을 구분해서 보고한다.
- 후속 실제 3D 모델의 완료 조건은 원본과 닮은 정면 얼굴/눈 비율·머리 컬·옷의 실루엣과 재질을 먼저 비교하는 것이다. 정면·양옆·누운 자세 검토를 거쳐 사용자가 외형을 채택한 후 일반 게임에 적용한다. 재질 색과 단순 도형만 비슷한 시안은 기본 외형을 대체하지 않는다.
- 새로운 캐릭터 이미지 제작 중단은 유지한다. 학교 조명·점멸·게임 판정·음향·다른 캐릭터는 변경하지 않는다.

## 검증

`npm test`, `git diff --check`. 로딩된 GLB가 있어도 명시적으로 시안을 선택하지 않으면 원본을 표시하는지, 명시한 비교/실패 복구가 가능한지 검증한다.

브라우저에서 기본 3-2의 원본 외형과 개발용 GLB 선택을 확인한다. 일반 시작→입장→복귀와 재시작 초기화를 확인하며, 2.5D 측면 한계는 미해결로 기록한다.
