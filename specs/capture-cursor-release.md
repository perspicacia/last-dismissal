# 영역 캡처를 위한 화면 고정과 커서 해제 (Issue #86)

사용자가 트랙패드 시점 이동 때문에 게임 화면의 영역 캡처가 불가능하다고 알려 주어 조작 보완을 요청했다. `mouse-look-comfort.md`의 기본 조작·토끼 판정은 유지한다.

- 탐색 중 P 또는 Esc 메뉴의 ‘화면 캡처’로 캡처 모드에 들어간다. 현재 장면을 고정하고 이동·시점·공포 이벤트·소리를 멈춘다. Pointer Lock과 진행 중인 드래그/Pointer Capture, 눌린 이동 키를 해제한다.
- 캡처 모드에는 일시정지 창이나 화면을 덮는 어두운 막을 표시하지 않는다. ‘계속하기 · P’ 버튼만 모서리에 둔다. 위치·시점·방문·토끼 배치와 활성 고양이의 상태를 보존한다. 별도 이미지를 생성/업로드하지 않고 사용자의 OS 영역 캡처를 돕는다.
- Mac의 Cmd+Shift+3/4/5와 Windows/Linux의 Win+Shift+S·Ctrl+Shift+S가 브라우저에 전달되면 캡처 모드에 들어가며 OS 단축키의 기본 동작을 막지 않는다. Cmd+Shift 조합이 먼저 전달되는 경우에도 커서를 미리 해제한다. OS가 모든 키를 가로채는 환경에서는 P를 먼저 누른다.
- Cmd/Ctrl/Alt가 포함된 키는 WASD 이동·E 문 이용·M 음소거로 처리하지 않는다. 드래그 중 해당 수식키를 누르면 기존 드래그를 정리하고 수식키를 놓기 전까지 시점/상호작용을 받지 않는다.
- 캡처 중 브라우저/캡처 도구로 포커스가 바뀌어도 장면 고정을 유지한다. P/계속 버튼으로 명시적으로 재개하고 Esc는 일시정지 설정 창을 연다. 재시작/처음 화면/종료에서는 캡처 UI·상태를 정리한다. 토끼 발견 후 돌진 중에는 캡처 모드로 종료 시간을 바꾸지 않는다.
- 일반 플레이에 상시 캡처 안내를 추가하지 않는다. P와 OS 캡처 안내는 일시정지 창/캡처 모드의 접근성 설명에 둔다. 버튼은 키보드 접근·보이는 포커스·44px 이상 높이를 제공한다.

## 완료 조건

단축키 식별·수식키 이동 차단·드래그 해제/늦은 잠금·캡처 중 장면/고양이 보존을 자동 검증한다. 실제 브라우저에서 탐색 → 드래그 → 캡처 → 입력/이벤트 정지 → 재개, Esc 메뉴 진입, 게임 오버/재시작을 확인한다. OS 캡처 키 전달 및 실제 영역 선택 확인과 브라우저 상태 검증을 구분해 기록한다.
