# 문·토끼 비명 레퍼런스 적용 (Issue #58)

사용자가 지정한 Pixabay `Opening Door`(DRAGON-STUDIO, 450444), `Monstrous Scream`(Alex_Jauk, 187949)을 학교 미닫이문과 토끼 공격 연출에 맞게 편집한다. 이전 합성 문/비명 음색을 녹음 기반 효과음으로 대체하는 최신 명세다.

- 두 음원은 로컬 WAV로 보관하고 출처·다운로드일·편집 내역·이용 조건을 `assets/audio/README.md`에 기록한다. 게임 실행 중 외부 사이트 연결은 필요 없다.
- 문은 목재/경첩 마찰을 포함한 원본 앞부분을 사용한다. 토끼는 낮고 거친 비명의 중간 부분을 사용하며 재생 속도를 올려 음색이 높아지지 않게 한다.
- 토끼 비명은 .55초의 이빨 공개 시점부터 한 번 재생하며 .88초 이내에 잦아들어 1.5초 게임 오버 전 끝난다. 문 효과음은 입장 시 한 번 재생한다.
- 시작 버튼 이후 AudioContext에서 미리 디코딩하고 캐시한다. 미완료/실패 시 기존 합성음으로 대체하며, 파일 로딩 완료가 지난 효과음을 뒤늦게 재생하지 않는다.
- 모든 효과음은 기존 master 음량·음소거를 거친다. 종료·복귀·재시작에서 재생 중인 효과음을 정리한다. 음소거 여부와 관계없이 게임 판정은 동일하다.
- 학생 인형의 2.5D 찌그러짐 원인과 실제 3D 메시·텍스처·자세 전환에 필요한 기능을 설명한다. 3D 캐릭터 제작은 사용자의 후속 채택 전 구현하지 않는다.

완료 조건: `npm test`, `git diff --check`, WAV 길이·피크·유효 데이터와 로딩 실패/음소거/캐시/정리 검증. 실제 브라우저에서 디코딩 및 시작→문 입장→토끼 발견→게임 오버→재시작을 확인한다. 실제 스피커에서의 청감과 모바일 확인 여부를 별도로 기록한다.
