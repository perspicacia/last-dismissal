# 音향·공포 이벤트 첫 확장

- 기존 토끼와 학생 인형의 낡은 장난감 분위기를 유지한다. 새 캐릭터 이미지는 만들지 않는다.
- 정상 연습 복도에서 열쇠·문 안내는 항상 명확하게 유지한다. 공포 이벤트로 이동·상호작용을 막지 않는다.
- 문을 열 때 짧고 낮은 불협화음과 안내방송 같은 음색을 낸다. 갑작스러운 큰 소리와 점멸은 사용하지 않는다.
- 토끼 이빨 공개 효과음은 같은 복도에서 한 번만 재생한다. 다음 복도나 재시작에서 상태를 초기화한다.
- 음소거 상태에서도 시각적인 안내와 판정 단서는 유지한다.
- 구현 모듈은 위치·렌더링 코드와 분리하고 개발 A와 정해진 인터페이스로 연결한다.
- 검증: 이벤트 중복 방지·초기화 테스트, 전체 테스트, 브라우저에서 문 개방과 재시작 흐름을 확인한다. 실제 청취 여부는 별도로 기록한다.
