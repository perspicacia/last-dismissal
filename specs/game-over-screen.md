# 전용 GAME OVER 화면 (Issue #76)

2026-10-04 사용자 요청: 게임 종료 화면이 옛 시작 화면처럼 보이는 것을 바꾸고 ‘Game Over’와 ‘다시 하기’ 버튼을 표시한다.

- 토끼 돌진 연출이 끝나면 첫 화면과 구분되는 검정/짙은 붉은 배경의 전용 종료 화면을 표시한다. 중앙에 큰 `GAME OVER`, 그 아래 `다시 하기` 버튼만 둔다. 이전 한글 제목/서사/방 설명과 헤더는 이 화면에서 표시하지 않는다. 캐릭터 이미지는 새로 제작하지 않는다.
- 버튼은 기존 새 게임 시작에 연결한다. 방문 기록/토끼 배치/등장/공포·음향 이벤트를 초기화하고 복도부터 다시 플레이한다. 클릭과 Enter/Space를 지원하고 종료 시 버튼에 키보드 포커스를 준다. Escape 첫 화면 복귀·음소거·토끼 발견 조건과 연출 시간은 유지한다.
- 데스크톱/세로 모바일/낮은 가로 화면에서 제목과 최소 54px 높이 버튼을 중앙에 배치하고 넘침을 막는다. 자동 점멸·스크롤 연출은 추가하지 않는다. 기본 첫 화면과 개발용 이전 탈출 화면은 유지한다.
- `npm test`, `git diff --check`; 실제 브라우저 시작 → 플레이 → 토끼 종료 → GAME OVER → 클릭/키보드 재시작 → Escape를 확인한다. Three.js/Canvas와 좁은 화면을 확인하며 실제 모바일 기기/청감은 별도로 미확인 기록한다.
