# 마지막 하교 — 목적과 범위

## 목적
야간 학교의 교실을 하나씩 확인하다 숨어 있는 인형을 발견하는 탐색 공포게임이다. 사용자 선택에 따라 토끼 발견 순간 공격·게임 오버로 끝난다.

## 현재 범위
- HTML/CSS/JavaScript와 Three.js. Canvas 호환 화면 유지.
- 복도와 3-1·3-2·3-3 교실·음악실·무용실, 문 앞 이름표와 방별 소품.
- 토끼는 시작 시 숨기고 새 게임마다 다섯 방 중 한 곳에 배치한다. 방 안쪽에 다가가 응시하면 즉시 돌진 후 게임 오버.
- 다섯 방을 모두 둘러보는 탐색 동선. 토끼를 먼저 만나면 그 순간 종료하므로 전부 방문이 보장되지는 않는다. 이번 규칙에는 탈출 승리가 없다.
- 화살표/WASD 이동·회전, E 입장/복도 복귀, M 음소거, Escape 처음 화면.
- 이동 발소리와 발견 효과음. 음소거에서도 같은 발견·종료 판정.
- 학생 인형은 기존 교실 장식, 창밖 귀신 공격은 후속 범위. 기존 캐릭터 추가 이미지 제작 중단 유지.
- 이전 60초 문 방어·계단 이상 판정은 일반 플레이에서 사용하지 않고 회귀 모듈로 보존.
