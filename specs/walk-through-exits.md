# 걷는 계단과 간결한 게임 화면

- 플레이 화면의 이동 버튼·조작 키 안내·위층/아래층 선택 버튼과 상시 목표 패널을 제거한다. 조작 설명은 시작 화면에서만 제공한다.
- 복도 끝 왼쪽 위층/오른쪽 아래층 계단 입구에 직접 걸어 들어가면 다음 구간으로 넘어간다. 중앙이나 교실에서는 전환하지 않는다.
- 첫 연습의 위층 입구는 닫혀 있고 아래층으로 걸어 내려간다. 정규 구간의 이상 유무와 정답/오답·5회 탈출 규칙은 유지한다.
- 확인표가 없으면 계단 진입을 막고 짧게 필요한 물건만 알린다. 열쇠·교실·확인표는 가까이서 나타나는 단순한 상호작용 버튼과 E로 조작한다. 버튼에 키 안내는 쓰지 않는다.
- 복귀 버튼은 교실에서만 표시한다. 재시작은 Escape로 시작 화면에 돌아가는 방식이며 시작 화면에 설명한다.
- 검증: 계단 영역과 중복 전환·중앙/교실 금지·연습·확인표 조건·5회 탈출 테스트, 브라우저에서 안내/선택 UI 제거·걷는 전환·재시작 확인.
