# 목재 교실 창문과 검은 고양이

2026-10-04, Issue #72. 사용자 요청: 참고 사진의 목재 미닫이창, 귀신 얼굴을 가리지 않는 유리칸, 간헐적인 음침한 고양이 울음, 검은 고양이의 무작위 등장.

## 창문

- 교실 다섯 곳의 외부 창문은 따뜻한 갈색 목재 테두리·두 미닫이 날개·작은 위 유리칸/큰 아래 유리칸·레일/손잡이/돌출 창턱으로 만든다. 복도 외부 창문은 이번 범위가 아니다.
- 가운데 가로 프레임을 얼굴 아래에서 위로 올리고 3-3/무용실 귀신은 큰 아래 유리칸 중앙에 맞춘다. 기존 PNG/표정/공포 판정을 유지하며 위치와 전체 균일 크기만 맞춘다.
- Three.js와 Canvas는 같은 창문·유리칸 치수를 쓴다. 얼굴·미소가 프레임을 뚫지 않고 보이며 창밖 공/풍경·실내 벽/동선을 유지한다.

## 고양이

- 검은 몸통·머리·뾰족한 귀·다리·긴 꼬리·탁한 황록색 눈을 가진 작은 입체 고양이를 코드로 만든다. 기존 인물 이미지는 변경/생성하지 않는다. Canvas는 같은 위치/시간의 실루엣 근사 표현이다.
- 플레이 중 복도/방마다 약 10~22초 뒤 무작위 방향으로 한 마리만 불쑥 나타나 1.6초 동안 앞쪽 바닥을 짧게 뛰어 지나간다. 안전한 위치/경로가 없으면 기다린다. 벽·책상·의자·고정 인물과 겹치는 경로를 배제한다. 반복 등장 사이에는 충분한 간격을 둔다.
- 처음 화면/방 이동/게임 오버/Escape/재시작은 고양이를 숨기고 해당 타이머를 정리한다. 일시정지/비활성 탭은 시간을 진행하지 않는다. 재시작 때 모델이 중복 생성되지 않는다.
- 고양이는 분위기 연출이며 토끼가 유일한 공격자다. 조작/판정/방문 기록을 바꾸거나 강제 카메라 회전/플래시·화면 점프스케어를 추가하지 않는다. 동작 줄이기에서는 같은 위치에 정지 자세로 나타났다 사라지는 표현을 사용한다.
- 독립된 간격(약 9~21초)으로 낮고 멀리서 들리는 울음 계열 합성음을 넣는다. 고양이 등장에도 한 번 재생하고 같은 프레임의 중복 울음은 합친다. 기존 아기 울음/귀신 웃음/문/토끼 효과음은 유지한다. master 음량/음소거, 방 이동/종료 효과음 정리와 신호 소비를 적용한다.

## 검증

`npm test`, `git diff --check`. 창문 치수/유리칸/귀신 얼굴의 시점 투영 여유, 실제 메시/Canvas 공유·기존 연출 회귀, 고양이 무작위 간격/한 마리·경로 여유/종료/음소거 독립·동작 줄이기·재시작, 울음 파형/피크/master 연결을 확인한다.

실제 브라우저에서 귀신 정면/근접·무용실/일반 교실 창문, 고양이/울음 호출·방 이동/숨김, 시작 → 플레이 → 토끼/게임 오버 → 재시작 → Escape, Canvas를 확인한다. 별도 개발용 재현 버튼/고정 난수는 일반 UI에 노출하지 않는다. 테스트 통과, 실제 화면 확인, 실제 청감·모바일/GPU 미확인을 구분해 기록한다.
