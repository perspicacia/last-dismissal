# 밤 학교 조명 (Issue #62)

- 실내 노출·주변광·달빛·천장등을 낮춰 밤 학교 분위기를 만든다. 문 이름표·이동 경로·가구와 캐릭터는 식별할 수 있어야 한다.
- 복도 다섯 전등은 위치별로 다른 시점에 약 1~2초간 소등된 뒤 복구한다. 짧은 밝기 전환을 사용하고 모든 등을 동시에 끄지 않는다. 전등 표면의 발광과 실제 광량은 같은 상태를 따른다.
- 교실 조명은 낮은 고정 밝기다. 창밖 가로등은 켜져 있으며 숲·운동장의 깊이를 남긴다. 공격·방문·이동·음향 판정은 바꾸지 않는다.
- 점멸 시계는 복도 플레이 중에만 진행하고 새 게임·재시작 때 초기화한다. 방 이탈·일시 중단 후 한꺼번에 상태가 진행되지 않게 프레임 시간 증가를 제한한다.
- `prefers-reduced-motion: reduce`에서는 복도도 고정 조명으로 표시한다. 음소거와 조명은 독립이다.
- Canvas 호환은 낮은 기본 조도와 위치별 전등 소등을 공유한다. Three.js와 같은 실제 공간 광원은 지원하지 않는다.
- 이전 `horror-events.md`의 점멸을 사용하지 않는 규칙은 이번 사용자의 요청으로 복도 전등에 한해 대체한다.

## 검증

`npm test`, `git diff --check`. 조명 주기·소등/복구·위치별 시차·동작 줄이기·중단/초기화와 실제 3D 광원/발광 표면 연결을 확인한다.

실제 브라우저에서 복도 켜짐/꺼짐과 문 식별·교실/창밖 조도, 시작→플레이→게임 오버→재시작을 확인한다. Canvas 강제 호환과 동작 줄이기 개발용 비교도 확인하며 실제 기기 성능·사용자 공포 강도 평가는 별도로 기록한다.
