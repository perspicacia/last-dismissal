# 교복 여고생 귀신 공격자

범위: [Issue #109](https://github.com/perspicacia/last-dismissal/issues/109).

2026-10-06 사용자 채택: 피 얼룩을 입힌 토끼가 귀엽다는 피드백을 반영해 현재 탐색 공격자를 긴 검은 머리·창백한 얼굴의 교복 여고생 귀신으로 교체한다. 신규 디자인/이미지 제작과 게임 적용은 사용자 요청으로 승인되었다.

- 기존 다섯 방 탐색과 새 게임마다 한 방 무작위 배치, 시작 복도/문 입구 숨김을 유지한다. 가까이서 응시해 발견하면 조작을 잠그고 패배를 확정한다. 발견 직전 두 표정 자산이 준비됐는지 확인해 보이지 않는 공격을 막는다.
- 발견 후 처음 짧은 정지 표정, 접근 중 공격 표정/비명, 1.5초 뒤 전용 GAME OVER/다시 하기로 연결한다. 기존 발견 거리/시야·판정·돌진 시각/음향 타이밍은 유지한다. 토끼용 팔 분할과 피 얼룩은 새 인물에 적용하지 않는다. 두 표정은 같은 프레이밍/인물/복장을 유지한다.
- 참고 이미지의 긴 검은 머리·창백하고 섬뜩한 얼굴을 참고하되 독자적인 인물로 제작한다. 낡은 밝은 블라우스, 어두운 교복/주름치마, 흐트러진 리본과 신발을 사용하며 과도한 유혈보다 어두운 눈과 얼굴 표정으로 공포를 만든다.
- Three.js는 공간 안의 사진 기반 캐릭터를 이동시킨다. Canvas도 같은 위치/시간/원본 비율을 공유한다. 정밀 조형/관절 애니메이션 모델이라고 보고하지 않는다. 기존 토끼는 과거 비교/회귀용 자산으로 보존하고 일반 탐색에서는 숨긴다.
- 첫 화면의 토끼 자리를 새 여고생으로 교체하고 다른 네 캐릭터와 어두운 포스터·영문 제목을 유지한다. 종료 이미지/접근성 설명도 새 귀신으로 맞춘다.
- 토끼 때부터 사용한 녹음 점프스케어를 발견 후 .55초에 한 번 재생한다. 전체 음량/음소거·조작/캡처 접근성·조명과 다른 분위기 요소는 유지한다.
- 시작/재시작/첫 화면에서 발견·표정·돌진 상태를 초기화하고 음소거에서도 동일하게 종료한다. 자산 로딩 실패는 안내하고 플레이를 계속하며 다음 시작에 재시도한다.

완료 조건: 새 PNG 두 장과 출처/프롬프트 기록, 발견/로딩/원본 비율·Three.js/Canvas 회귀 테스트, 전체 테스트와 실제 시작→발견→돌진→GAME OVER→재시작 검증, docs/progress.md 기록, 별도 브랜치 PR.
