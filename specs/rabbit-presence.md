# 토끼의 교실·첫 화면 등장 복구 (Issue #115)

사용자 채택: 여고생 귀신을 공격자로 바꾸더라도 토끼도 게임에 등장해야 한다. [Issue #115](https://github.com/perspicacia/last-dismissal/issues/115)에서 여고생은 공격자, 토끼는 비공격 분위기 캐릭터로 역할을 분리해 복구한다. 이 명세는 이전 공격자 교체 문서의 일반 게임/첫 화면 토끼 숨김 규칙을 대체한다.

- 기존 두 토끼 PNG와 코드 기반 피 얼룩·원본 비율을 유지한다. 새 캐릭터 이미지·음향은 만들지 않는다.
- 3-1 교실 안 책상 사이의 빈 통로에 한 마리를 배치한다. 시작 복도에는 보이지 않고 첫 화면에는 여고생과 함께 여섯 번째 인물로 포함한다.
- 기본 무표정, 가까이서 바라보면 기존 이빨 표정을 사용한다. 돌진·팔 만세·비명·게임 오버를 추가하지 않는다. 토끼와 여고생의 표정 상태는 독립한다.
- 토끼의 근접/응시가 방문 수·공격자 방 난수·여고생 발견 조건을 바꾸지 않는다. 여고생은 여전히 다섯 방 중 하나에 숨는 유일한 공격자다. 같은 방에 있어도 토끼 위치를 바라보는 것만으로 별도의 패배가 발생하지 않는다.
- Three.js와 Canvas는 같은 위치·높이·원본 비율·표정 조건을 사용한다. 준비되지 않은 사진은 표시하지 않고 기본 이미지만 준비되면 기본 표정을 사용한다. 이미지/텍스처는 기존 로더와 캐시를 재사용한다.
- 방을 떠나거나 종료/첫 화면/재시작하면 토끼 표시/표정을 정리한다. 일시정지/캡처는 기존 장면 고정을 유지하며 새로운 자동 시점·움직임을 넣지 않는다. 음소거와 동작 줄이기에서도 동일하게 확인할 수 있다.

완료 조건: 비공격/표정 독립/이미지 지연·방 이동/종료/재시작·원본 비율의 회귀 테스트, 전체 테스트 및 실제 시작→3-1 토끼 확인→여고생 발견/GAME OVER→재시작을 확인한다. 첫 화면의 모든 인물·제목·시작 버튼, Canvas 호환 표시도 확인하고 `docs/progress.md`에 자동 검증/실제 플레이/한계를 구분해 기록한다.
