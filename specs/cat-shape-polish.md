# 검은 고양이 체형 연결 보완

2026-10-07 사용자 요청, [Issue #122](https://github.com/perspicacia/last-dismissal/issues/122): 고양이의 어설픈 모양을 기존 스타일 안에서 수정한다. 이전 `black-cat-polish.md`와 `cat-boy-likeness.md`의 역할·보행·음향 규칙은 유지한다.

- 코드 기반 검은 털·금빛 아몬드 눈/세로 동공·넓은 삼각 귀·짧은 주둥이·수염·올라간 긴 꼬리를 유지한다. 머리–가슴·등/엉덩이 비율과 표면, 귀의 두께/위치, 발로 내려오는 다리 굵기를 실제 밝은 비교 픽셀에 따라 보완한다.
- 기존 접지 관절과 3초 등장·한 마리·.58m 수평 경로 여유·무작위 시간·가속/감속·동작 줄이기·방 이동/종료/재시작 정리를 유지한다. Canvas는 수정 체형과 같은 실루엣을 사용한다.
- 사람 캐릭터·원본 PNG/GLB·공격 판정·카메라·학교 조명·음향은 변경하지 않는다. 새 이미지/외부 모델·프로그램 설치·main 병합·배포는 하지 않는다.
- 밝은 정면·45도·측면·후면 및 실제 복도/교실 조명, 얼굴 확대·발 접지/들기·연속 보행과 Canvas를 확인하고 전후 캡처를 보관한다.
- 전체 `npm test`, 표면 연결/유한 좌표·발 접지/안전 여유·재사용·이벤트 수명주기 회귀, 구문 검사·`git diff --check`를 통과한다. 실제 브라우저 검증과 자동 검사, 독립 Mac Chrome headless/SwiftShader와 사용자 GUI/청감·GPU 성능 미확인을 구분한다.
- 원본 스타일을 코드로 근사한 모델임을 명시하며 전문 털/골격 자산 완성으로 보고하지 않는다. 완료 근거와 다음 작은 작업을 `docs/progress.md`에 기록하고 별도 브랜치 검토 PR로 제출한다.
