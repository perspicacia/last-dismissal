# 음악실 피아노 의자의 어린 남자아이 귀신 (Issue #66)

2026-10-06: 음악실 남자아이의 최신 외형은 [원본 일치 명세](cat-boy-likeness.md)가 우선한다. 구형 부품별 사진 투영 대신 원본 윤곽·XY/UV를 보존한 앞면과 별도 뒤 볼륨을 연결한다. 기존 좌석/발 높이·위치·비공격 규칙은 유지한다.

2026-10-04: 아래 이미지 평면 구현은 초기 기록이다. 현재 Three.js의 닫힌 3D 메시·원본 사진 투영·좌석 높이는 [교실 입체감 명세](classroom-character-depth.md)가 우선한다. 기존 자산/위치/비공격 규칙과 Canvas 사진 투영은 유지한다.

- 사용자는 음악실 의자의 학생 인형 대신 주온의 토시오 같은 어린 남자아이 귀신이 앉아 있는 외형을 요청했다. 새 실사풍 투명 PNG를 한 개 제작한다. 기존 캐릭터의 추가 이미지 제작 중단은 유지하되 이번 신규 귀신 제작은 사용자 요청 범위다.
- 창백한 피부, 짧은 검은 머리, 어두운 눈과 멍한 시선, 낡은 밝은 상의/반바지와 맨발. 자세는 의자에 골반/허벅지가 닿고 무릎을 굽혀 다리가 아래로 내려오는 모습이다. 손은 무릎 위에 놓는다. 피아노를 등지고 중앙 통로 쪽을 바라보는 구도로 배치한다.
- 음악실의 기존 학생 인형 배치만 제거한다. 피아노 의자 중심 `(2.68, 7.35)`와 좌석 높이 `.525m`에 맞춰 새 귀신을 정적으로 연결한다. 중앙 탐색 동선과 기존 가구 충돌 범위를 유지한다.
- Three.js에서는 의자에 정렬한 고정 방향의 이미지 평면을 사용하고 Canvas 호환에서도 같은 좌석/크기/방향을 표현한다. 지지면/발 접촉 그림자를 더한다. 이는 실제 관절형 3D 모델이 아닌 이미지 기반 캐릭터다.
- 이미지 원본 비율을 유지하고 전체를 균일 크기로 배치한다. 로딩 완료 후 표시하며 로딩 중/실패는 게임을 막지 않는다. 재방문/재시작마다 중복 생성하지 않는다.
- 최종 이미지 평면은 `(2.43, 7.35)`에 둔다. 좌석 앞면보다 4cm 앞에서 표시해 허벅지/다리가 의자 앞판과 겹쳐 잘리지 않게 한다. 1024×1536 원본에서 지지점 y=957px·발끝 y=1509px를 사용해 좌석 `.525m`와 발 `.025m`를 맞춘다. 응시할 때 카메라는 앉은 몸/근접 얼굴을 향해 완만하게 내려간다.
- 새 공격·게임 오버·효과음·표정/추적 애니메이션은 추가하지 않는다. 현재 공격자는 토끼이며 음소거와 판정은 독립이다. 기존 학생 인형·토끼·창밖 귀신·학교 조명은 유지한다.

## 검증

`npm test`, `git diff --check`. 음악실 학생 인형 제거·귀신 위치/방향/비율·좌석 맞춤·정면/측면 표시·이미지 미완료/실패·중앙 동선을 검증한다.

실제 브라우저에서 음악실 입장·정면/근접 시점의 좌석 접촉, 복귀·토끼 게임 오버·재시작을 확인한다. Canvas 호환과 소리 출력 없는 검증을 구분해 기록한다. 측면의 이미지 평면 한계와 새 캐릭터의 체감 공포 강도는 명시한다.
