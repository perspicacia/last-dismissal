# 음악실 남자아이 무료 인체 모델 연결

2026-10-06 사용자 채택: 무료 3D 모델을 활용하되 기존 이미지의 얼굴·머리·의상 느낌을 유지하고 몸통의 입체감을 보완한다.

범위: [Issue #107](https://github.com/perspicacia/last-dismissal/issues/107). 음악실 남자아이 한 명을 대상으로 한다.

- Sketchfab 후보는 다운로드에 계정 로그인이 필요하다. 로그인 없이 배포되는 Quaternius Universal Base Characters Standard(CC0)의 남성 기본 인체를 대체 기반으로 사용한다. 유료 Source 버전은 사용하지 않는다. 출처·원본 라이선스·변형 내용을 저장소에 남긴다.
- 원본 `assets/piano-boy-ghost.png`와 첫 화면을 보존한다. 무료 모델의 얼굴·헤어·피부색으로 교체하지 않는다. 원본 사진의 얼굴 비율을 유지하는 앞면과 머리 뒤 볼륨을 연결하고, 무료 인체의 몸통/사지 표면은 어린아이 비율·앉은 자세로 조정한다. 낡은 밝은 상의·반바지·맨발과 무릎 위 손을 유지한다.
- 원본 알파 윤곽을 깊이 방향으로 늘려 만든 기존 몸통을 대체한다. 가슴·등·어깨·허벅지·종아리의 실제 연결된 표면과 좌석 접촉을 갖춘 로컬 GLB를 사용한다. 측면/후면에는 얼굴 사진을 반복하지 않는다.
- 얼굴은 원본 사진 기반 표현이며 완전한 얼굴 조형으로 보고하지 않는다. 새로운 이미지 제작은 하지 않는다. 정면 모습과 옆/뒤 몸통을 밝은 비교 화면에서 함께 확인한다.
- 위치·방향·의자/바닥 접촉·정적 비공격 역할과 Canvas 원본 투영을 유지한다. 조명·카메라·음향·다른 캐릭터·토끼·진행·재시작 규칙은 변경하지 않는다.
- 원본 이미지를 먼저 표시하고 로컬 모델이 준비되면 실제 몸통으로 교체한다. 실패 시 기존 사진 기반 볼륨을 유지한다. 음악실의 다음 입장에 재시도하며 매 프레임 반복 요청이나 중복 모델을 만들지 않는다. 외부 서비스는 게임 실행에 필요하지 않다.

## 완료 조건

- 모델 출처/CC0 문서와 재현 가능한 변환 스크립트를 보관한다. 원본 무료 모델의 머리/얼굴/눈은 게임에 들어가지 않는다.
- 실제 인체 메시·몸통 깊이·유한 좌표·좌석/발 접촉·원본 얼굴 UV·로딩/실패/재사용을 검증한다. 이전 사진 깊이 테스트는 보존된 이전 방식의 회귀 검증으로 구분한다.
- 밝은 정면·양쪽 사선·측면·후면과 실제 음악실 근접 시점을 확인하고 증거를 남긴다. 원본과 다른 부분/미확인 사항을 명시한다.
- 목의 윗부분은 원본 턱 아래를 지지하도록 연결한다. 측면에서 목이 뒤로 물러나 턱 아래가 사각 판처럼 드러나는 틈을 줄이고, 머리 하단 봉합면은 원본 피부색을 사용한다. 원본 얼굴 랜드마크와 어깨/몸통·좌석/발 접촉을 유지한다.
- 2026-10-06 후속 수정: 사용자가 팔/다리의 기괴한 형태와 축소된 옷을 지적했다. 관절 주변의 구간별 확대를 제거하고 손목/무릎/발목을 원본에 맞는 비율로 연결한다. 원본의 헐렁한 짧은 소매와 반바지는 인체 표면의 사진만으로 표현하지 않고 독립된 입체 의상 표면으로 구현한다. 손은 무릎 위, 발은 바닥에 두고 좌석을 관통하지 않는다. 밝은 정면/사선/측면/후면에서 옷 폭·관절·손/발 실루엣을 함께 확인한다.
- 전체 자동 테스트·구문 검사·`git diff --check`와 실제 브라우저 시작→음악실 탐색→GAME OVER→다시 하기 흐름을 확인한다.
- 작업·검증 결과를 `docs/progress.md`에 기록하고 별도 브랜치의 PR로 제출한다.
