# 토끼 만세 놀래키기 (Issue #48)

- 숨은 토끼 발견·기본→이빨·비명·게임 오버 흐름은 유지한다.
- 기존 PNG에서 몸과 좌우 팔을 런타임 마스크로 분리한다. 내려간 팔을 몸 텍스처에서 제거하고 같은 팔을 어깨 중심으로 회전시켜 중복 팔이 남지 않게 한다. 새 캐릭터 이미지 파일은 제작하지 않는다.
- 기본 등장에서는 팔을 내린다. 발견 후 .35~.70초에 양팔을 번쩍 올려 얼굴 옆의 만세 자세를 만든다. 이빨·비명(.55초)과 겹치게 한다.
- Three.js에서는 몸과 관절 팔을 별도 빌보드로, Canvas에서는 동일한 마스크·관절 좌표로 표현한다. 원본 비율을 유지한다.
- 동작 줄이기는 .55초에 올린 마지막 자세로 전환하고 회전 보간을 생략한다. 다시 시작하면 원래 자세로 초기화한다.

## 검증
`npm test`, `git diff --check`. 팔 회전 시점·양쪽 대칭·원본 비율·초기화와 기존 테스트를 확인한다. 브라우저에서 팔 내림/들림 외형, 중복 팔/어깨 틈, 표정·비명·종료·재시작을 확인한다.
