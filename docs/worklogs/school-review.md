# 교실 확장 검토

- 검토 Agent는 읽기·검증만 수행했다. 교실 입장·복귀 위치/방향 복원, 교실 계단 차단, 확인표 보유 유지, 새 게임 초기화를 확인했다.
- P2 교탁 통과 재현: `{x:-0.5,z:8,angle:0}`에서 `moveClassroomPlayer` 전진을 0.05초씩 6회 호출하면 z=9.14로 교탁을 통과했다. 렌더링과 충돌에서 교탁 geometry를 공유하고 반복 전진 차단·측면 통로 테스트를 추가하여 수정했다.
- 입장 E와 조사 버튼 E 문구가 다른 행동을 가리키던 안내를 수정했다. 입장은 E/큰 버튼, 문 번호 조사는 별도 조사 버튼으로 명시한다.
- 확인표 획득 상태를 렌더러에 전달하여 획득 후 종이가 남는 표시 문제를 방지했다.
- root 실제 브라우저 검증과 자동 검증 결과·미확인 사항은 `docs/progress.md`에 기록했다. 최종 자동 테스트 26개 통과.
