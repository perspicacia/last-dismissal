# 교실 인물 입체감과 칠판 보완 (Issue #74)

2026-10-04 사용자 요청: 음악실 남자아이·3-3 얼굴 없는 남학생의 납작함 보완, 의자에 앉아 있는 여학생 뒷모습, 높이가 충분한 칠판/분필/지우개/오늘의 당번.

- 남자아이와 얼굴 없는 학생은 원본 PNG의 얼굴·머리·옷·비율을 기준으로 둥근 머리/몸통/관절·팔/다리·신발의 닫힌 3D 메시를 만든다. 앞면은 기존 이미지의 사진 질감을 투영하고 옆/뒤는 피부·머리·옷 재질과 실제 두께로 연결한다. 기존 이미지 추가 제작/변형은 하지 않는다. 단순 판의 두께만 늘리지 않는다.
- 기존 위치·음악실 좌석/발 높이·3-3 벽 여유·통로를 유지한다. 이미지 로딩 전/실패는 숨기며 모델은 한 번 만들고 재방문/재시작에서 재사용한다. 완전한 고정 3D 형태지만 한 장의 정면 사진에서 복원한 근사 외형임을 기록한다. 리깅/추적/새 공격은 추가하지 않는다.
- 3-2의 오른쪽 가운데 책상 의자에 긴 검은 머리·어두운 교복·흰 양말의 여학생을 코드 기반 3D로 만든다. 칠판을 향해 앉아 있어 입구에서 뒷모습이 보인다. 좌석/발 접촉과 중앙 통로/기존 가구 충돌을 지킨다. 정적 분위기 요소이며 새 공격·소리·점프스케어는 없다. 기존 여학생 인형은 별도로 보존한다.
- 여학생을 가까이서 응시하면 기존 앉은 남자아이처럼 카메라를 완만하게 내려 앉은 몸/좌석이 보이게 한다. 멀리 있거나 시선 밖에서는 적용하지 않고 여학생을 향한 접근 판정만 사용한다. 공격 판정은 없다.
- 일반 교실 세 곳의 칠판은 폭 약 5.4m, 높이 약 1.55m의 진한 녹색 판·알루미늄 프레임·두께 있는 받침으로 교체한다. 받침에 실제 분필과 펠트/목재 지우개를 둔다. 분필 글씨로 반 이름과 ‘오늘의 당번’, 가상의 학생 이름을 적고 지워진 자국을 더한다. 플레이 안내 문구로 사용하지 않는다.
- Three.js는 입체 메시를 사용한다. Canvas 호환은 남학생 둘의 기존 원본 사진 투영을 보존하며 여학생은 같은 위치/자세의 실루엣 근사, 칠판은 같은 치수/문구를 사용한다. 사진 밑에 큰 타원 볼륨을 겹쳐 생기는 밝은 테두리는 피한다. Canvas의 남학생 측면 평면 한계는 남는다. 토끼 발견/종료·음향·조명·고양이와 첫 화면은 유지한다.
- `npm test`, `git diff --check`. 실제 머리/몸/사지 깊이와 사진 UV/동일 재사용·이미지 미완료/실패·좌석/벽/충돌 여유, 칠판 높이/소품/문구/공유 치수와 비공격 판정을 검증한다. 브라우저 정면/양옆/뒷모습, 교실 입장/복귀→토끼 종료→재시작→Escape, Canvas를 확인하고 자동 테스트와 구분한다. 실제 모바일/GPU 성능·사용자 외형 채택은 미확인으로 기록한다.
