# Three.js 학교 공간 전환

Issue #26. 기본 게임 화면을 Three.js WebGL 렌더링으로 전환한다.

- 기존 세계 좌표, 화살표/WASD 조작, 교실 출입과 충돌, 계단 진입, 이상현상 5종, 소리와 재시작 규칙을 보존한다.
- 복도·교실·계단·가구·창틀은 실제 3D 메시로 구성하고 재질·조명·그림자로 입체감을 표현한다.
- 창밖은 평면 반복 텍스처 대신 거리별 숲, 길, 운동장, 가로등을 배치한다. 교실과 복도는 다른 방향의 풍경이다.
- 단체사진·시계 디자인·토끼 기본/이빨·귀신 이미지는 재사용한다. 캐릭터 이미지는 평면 자산이며 3D 캐릭터 모델 전환은 이번 범위 밖이다. 학생 인형 제작 중단 유지.
- Three.js 버전 고정 및 MIT 라이선스를 기록하고 브라우저는 로컬 vendor 모듈을 읽어 외부 CDN 없이 실행한다. 기존 Canvas 렌더는 개발용 비교 화면에 보존한다.
- 완료 조건: npm test, 3D 정상/이상 비교, 실제 시작·교실 출입·계단 전환·재시작, 엔딩 확인. 브라우저에서 확인하지 못한 항목은 구분해 보고한다.
