# 음악실 남자아이 앞뒤 곡면 보완

2026-10-06, Issue #103. 사용자 요청: 남자아이 캐릭터의 입체감이 여전히 어색하므로 기존 외형을 유지하며 보완한다. 이 문서는 `cat-boy-likeness.md`의 남자아이 앞면을 얕게 유지하는 규칙을 갱신한다.

- 밝은 측면 비교에서 앞면이 수직 판처럼 남고 뒤만 큰 덩어리로 부풀어 있는 문제가 확인됐다. 얼굴·흉곽·팔·손·앉은 허벅지·종아리·발의 앞뒤 표면을 함께 조형한다. 얼굴의 눈·코·턱은 완만한 실제 깊이를 갖되 원본의 XY와 UV 대응을 유지한다.
- `assets/piano-boy-ghost.png`와 첫 화면은 보존한다. 새로운 이미지나 다른 캐릭터 디자인으로 교체하지 않는다. 후면에 얼굴 사진을 반복하지 않고 머리/피부/옷의 색과 표면을 구분한다.
- 머리/몸통의 과도한 뒤 팽창과 등 단면의 가로 굴곡을 줄이고, 무릎을 앞으로 내민 앉은 자세와 의자/맨발 접촉을 유지한다. 메시의 닫힌 표면과 유한 좌표, 원본 로딩 대기/실패/재시도 및 재방문 재사용을 보존한다.
- 음악실 위치·방향·정적 분위기 역할은 유지한다. 토끼 공격, 카메라/접근성, 조명, 음향, 게임 난수/진행/재시작 및 다른 캐릭터는 변경하지 않는다. Canvas 대체 렌더는 기존 원본 사진 표시를 유지한다.

## 완료 조건

- 밝은 비교 화면 정면·사선·측면·후면과 실제 음악실에서 외형을 확인한다. 후면 비교 버튼을 제공한다.
- 얼굴의 원본 비율, 앞뒤 깊이, 좌석/발 접촉, 닫힌 메시, 로딩/재사용 관련 테스트와 전체 테스트, JS 구문 검사 및 `git diff --check`를 통과한다.
- 시작→탐색→토끼 게임 오버→재시작을 실제 브라우저에서 확인한다. 자동 테스트와 실제 브라우저 확인을 구분해 기록한다.
- 한 장의 사진으로 보이지 않는 옆/뒤를 정확히 복원할 수는 없다. 이번 표면도 코드 기반 근사이며, 정밀한 전 방향 모델은 측면/후면 자료와 전용 조형·UV 작업이 필요하다는 한계를 기록한다.
