# 계단실 벽 틈 수정

Issue #32. 하강 입구에서 중앙 칸막이 뒤로 배경과 반대편 계단이 보이는 구조를 막는다.

- 입구에만 있던 중앙 벽을 계단실 끝 z31까지 연장한다. 하강 최저 발판부터 상행 천장까지 막는다.
- 계단실 바깥 벽은 복도 끝 z24.6에서 이어지고 천장은 뒷벽까지 닿도록 맞춘다.
- 계단 입구 두 개, 발판, 난간, 기존 진행 판정·이동 범위는 유지한다.
- 중앙 벽/외벽 범위 회귀 테스트, npm test, 구문 검사, git diff --check를 실행한다. 실제 렌더에서 하강 입구 안쪽과 양옆 회전 시 벽 막힘 및 위/아래 계단 가시성을 확인한다.
