# 음악실 남자아이 근접 얼굴 보완

2026-10-06, Issue #105. 사용자가 남자아이 얼굴의 반복되는 찌그러짐을 지적했다. 실제 음악실 근접/사선에서 큰 이마와 눌린 턱을 재현했다. 이 문서는 `piano-boy-depth-repair.md`의 얼굴 조형 완료 기준을 갱신한다.

- 머리 전체 타원에 사진을 굽히면서 눈·입·턱의 깊이가 크게 달라지는 원인을 보완한다. 중앙 얼굴 특징은 완만한 깊이로 연결하고 머리 옆/뒤의 닫힌 입체 볼륨은 유지한다. 사진의 눈·입을 측면 색 전환으로 지우지 않는다.
- 원본 PNG·첫 화면·XY/UV 대응과 앉은 몸의 깊이/좌석·발 접촉을 유지한다. 카메라/접근성·학교 조명·다른 캐릭터·음향·공격/진행/난수/재시작은 변경하지 않는다. Canvas 원본 투영은 보존한다.
- 밝은 비교 화면에 얼굴 확대 정면과 양쪽 사선을 추가한다. 실제 음악실 근접 정면/사선과 전체/측면을 함께 확인한다. 얼굴을 가리거나 조명을 낮춰 결함을 숨기지 않는다.
- 눈·코·입·턱 랜드마크의 근거리 투영 비율과 깊이/사진 유지, 닫힌 메시·유한 좌표·좌석 접촉·실패 재시도/재사용 테스트 및 전체 테스트/구문/diff 검사를 통과한다. 얼굴 깊이를 크게 만들수록 좋다는 이전 테스트 기준은 원본 얼굴 안정성 기준으로 대체한다.
- 실제 브라우저의 시작→탐색→GAME OVER→다시 하기와 콘솔 오류 여부를 기록한다. 한 장의 정면 사진에 없는 옆/뒤 디테일은 근사라는 한계를 명시한다.
