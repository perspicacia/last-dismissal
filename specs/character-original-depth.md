# 기존 캐릭터 외형을 유지하는 입체 보완

사용자 요청: 남자 마네킹, 검은 고양이, 앉은 여학생, 누운 금발 인형의 첫 외형을 최대한 유지하면서 입체감을 개선한다.

## 범위

- 금발 인형은 원본 PNG의 XY·UV·얼굴/의상 비율을 유지한다. 기존 14cm 균일한 부조 대신 머리·몸통·팔·다리의 서로 다른 둥근 깊이와 얼굴 굴곡을 사용한다. 머리 깊이의 기준은 약 26cm이며 실루엣 경계는 얇게 봉합한다. 옆/뒷면에 사진을 반복하지 않는다. 원본을 대체하는 새 GLB 제작은 이번 범위가 아니다.
- 얼굴 없는 남학생은 원본 사진의 머리/교복 비율을 유지하면서 턱·목·어깨·허리의 연결을 조형한다. 앞면 사진은 기존 투영 좌표를 사용하고 뒷면에는 얼굴을 반복하지 않는다.
- 여학생은 긴 검은 머리와 어두운 교복·흰 양말·검은 신발을 유지한다. 굵은 머리카락 튜브와 공 모양 몸통을 연속적인 머리카락 덩어리·어깨/등·접힌 치마로 보완한다. 기존 의자 접촉 위치와 정적 뒷모습을 유지한다.
- 고양이는 사용자 참고의 검은 털·금빛 눈·긴 코·곧은 귀를 유지한다. 겹친 볼/이마의 공 모양을 줄이고 눈과 코를 곡면에 연결한다. 기존 네 다리 접지·3초 등장·경로·음향·정리 규칙은 유지한다.
- 신규 이미지 생성, 새로운 공격/방문 판정, 음향·카메라·조명 변경은 하지 않는다. 원본 PNG 파일은 수정하지 않는다.

## 완료 조건

- 일반 게임과 별도 외형 비교에서 정면·사선·측면/누운 모습을 확인한다. 비교 화면은 게임 UI에 노출하지 않는다.
- 닫힌 메시, 유한한 좌표/노멀, 원본 투영 비율, 바닥/의자 접촉, 보행 경로 여유와 모델 재사용을 검증한다.
- 자동 테스트와 실제 브라우저 외형 확인을 구분해 기록한다. 단일 정면 사진으로 알 수 없는 옆/뒷면의 근사 한계를 명시한다.
- 원본과 동일한 모든 각도의 완전한 모델이 필요하면 Blender 등의 조형/UV·재질 작업과 GLB 파일, 고양이에는 골격/보행 애니메이션이 필요함을 설명한다. 후속 완전 3D 인형은 `student-doll-original-look.md`의 사용자 외형 검토 후 적용한다.

이 명세는 이번 개선에 한해 `student-doll-sides.md`의 14cm 깊이/완전 평면 얼굴 기준을 대체한다. 원본 외형 우선·이미지 로딩·봉합·기존 플레이 규칙은 유지한다.
