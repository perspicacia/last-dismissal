# 편안한 시점 설정과 대체 입력

관련 [Issue #101](https://github.com/perspicacia/last-dismissal/issues/101). 사용자가 제안된 조작 개선을 공식 게임 접근성 지침에 따라 적용하도록 요청했다.

기준은 [Microsoft XAG 117](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117)의 좌우/상하 감도 조절·자동 카메라 움직임 제한과 [XAG 107](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/107)의 대체 키보드 입력이다. 이번 범위는 시점 조작이며 전체 지침 준수 인증이나 모든 플레이어의 멀미 해소를 뜻하지 않는다. 아래는 [기존 시점 명세](mouse-look-comfort.md)의 단일 감도 규칙을 대체한다.

- WASD 전후/옆걸음과 화살표 이동/느린 회전, E/클릭 문 이용, Esc 일시정지와 P 캡처 규칙을 유지한다. 보행 흔들림·자동 시점·관성/가속은 사용하지 않는다.
- 좌우 기본 감도 65%, 상하 기본 감도 32.5%로 분리한다. 일시정지 메뉴에서 좌우 20~180%(5% 간격), 상하 10~180%(2.5% 간격)로 독립 조절한다. 양쪽 모두 기본값의 절반 이하/1.5배 이상을 선택할 수 있다. 위아래 ±60도 제한은 바닥의 장식을 살펴볼 수 있도록 유지한다. 기본값은 편안함 비교용이며 사용자 체감 확인은 별도다.
- ‘상하 시점 고정’은 기본 꺼짐이다. 켜면 일시정지 중 정면 높이(pitch 0)로 돌려놓고 이후 마우스/드래그/키보드의 상하 입력을 무시한다. 좌우 회전·이동·정면에 있는 토끼 발견은 계속 가능하다. 아래/위만 보는 상태에 갇히지 않는다. 고정을 끄면 정면에서 자유 상하 조작을 다시 시작한다.
- 고정 중 상하 감도 슬라이더를 비활성화하고 이유를 설명한다. 다시 끄면 이전 상하 감도를 복원한다. Tab 포커스는 비활성 컨트롤을 건너뛰며 설정과 계속/캡처/처음 화면을 순환한다. 레이블·수치·보이는 포커스·44px 이상 조작 영역을 제공한다.
- 마우스를 사용하지 않아도 Page Up/Down으로 위/아래를 3도씩 보고 Home으로 정면 복귀한다. 키 반복도 지원한다. 설정 화면에서는 해당 키가 게임 시점을 변경하지 않는다. Cmd/Ctrl/Alt 단축키, 캡처/일시정지/공격 중 입력은 기존대로 차단한다.
- 시점 설정은 재시작·처음 화면·방 이동에서 유지하고 같은 브라우저 새로고침에서도 로컬 저장값을 불러온다. 저장을 사용할 수 없거나 데이터가 손상됐으면 기본값으로 시작하며 플레이를 막지 않는다. 설정 저장에 게임 배치/난수/공포 상태를 포함하지 않는다.
- 토끼의 수직 응시 판정·돌진/비명/만세·GAME OVER/재시작은 보존한다. 카메라 높이는 1.5m로 고정하며 모델/음향/조명은 변경하지 않는다. Three.js와 Canvas 호환 입력에 같은 설정을 사용한다.

완료 조건: 독립 감도·고정/해제·키보드 시점·잘못된 값/저장 실패·수직 토끼 판정을 자동 검증한다. 실제 브라우저에서 드래그·설정/Tab·일시정지/캡처·새로고침 유지와 시작→탐색→게임 오버→재시작을 확인한다. Pointer Lock/실제 장치 및 사용자 체감 확인과 자동 검증을 구분해 기록한다.
