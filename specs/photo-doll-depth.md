# 게시판 사진과 인형 입체감

Issue #34. 게시판 사진이 프레임보다 높게 나오는 문제와 누운 인형의 평면 외형을 수정한다.

- 1.78×0.98 게시판 안에 3:2 사진을 1.32×0.88로 배치하고 가운데 정렬해 여백을 확보한다. 정상/지워진 사진에 동일하게 적용한다.
- 기본 인형 이미지의 알파 실루엣으로 닫힌 입체 볼륨을 만든다. 머리·몸통·치마·팔다리의 곡면 두께, 측면 재질과 실제 그림자를 제공한다. 원본 이미지와 표정 자산은 보존한다.
- 누울 때 뒷면이 바닥에 닿고 얼굴과 몸체는 바닥 위로 솟도록 한다. 기립/표정 전환/응시 거리와 게임 판정은 유지한다.
- 관절형 캐릭터 모델 대신 기존 이미지에 곡면과 두께를 준 입체 볼륨이다. Canvas 호환은 기존 렌더를 유지한다.
- 검증: 사진 프레임 내 여백, 인형 닫힌 두께/투명 배경 제거/로딩 대기 테스트, npm test, 실제 브라우저 정상/이상 사진과 인형 누움·옆모습·기립 확인.
