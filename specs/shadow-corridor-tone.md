# 그림자복도 참고 학교 톤 (Issue #95)

- 사용자 요청은 전체 분위기를 일본 공포게임 Shadow Corridor(그림자복도)와 비슷한 톤으로 맞추는 것이다. 공식 [Steam 스크린샷](https://store.steampowered.com/app/1025250/Shadow_Corridor/)의 어두운 공간과 따뜻한 국소 광원 대비를 참고한다. 참고 이미지를 게임 자산으로 복제하지 않는다.
- 선택 질문의 기본 방향 ①(차가운 암부 + 따뜻한 전등, 낮은 채도)을 학교 공간에 적용한다. 참고작의 모든 장면이 같은 색이라는 뜻은 아니며, 일본식 건물로 맵을 교체하지 않는다.
- 복도/교실의 전등은 낡은 누런빛, 창가/먼 공간의 주변광과 안개는 청회색이다. 조명이 닿는 구역과 구석의 깊은 그림자를 대비시키면서 문 이름표, 바닥/가구 경계, 귀신 얼굴을 구분할 수 있어야 한다.
- 벽/걸레받이/목재 색을 낮은 채도로 통일하고 항상 같은 습기/때 자국을 학교 벽 질감에 추가한다. Three.js 물리 광원의 범위와 색을 조정하고 Canvas의 벽/천장/전등에도 같은 팔레트를 반영한다. 전체 화면의 낮은 채도/가장자리 암부는 두 렌더가 공유하며 UI 글자에는 적용하지 않는다.
- 시작/게임 오버의 기존 다섯 귀신 포스터·영문 제목·GAME OVER/다시 하기 구성을 유지하고, 배경의 붉은 광량과 차가운 암부를 조정해 플레이 화면과 이어지게 한다. 피 얼룩 토끼와 원본 캐릭터 사진/입체 보완은 유지한다.
- 카메라 흔들림/흐림/색수차/노이즈 애니메이션과 새 플래시는 추가하지 않는다. 기존 복도 전등 소등/복구·동작 줄이기와 일시정지/캡처/재시작 규칙을 유지한다.
- 게임 방문/토끼 발견/돌진/비명/만세 시간, 음향·조작·충돌은 보존한다. 공격자는 여전히 토끼 하나다. 캐릭터 외형 비교 화면의 밝은 검토 조명은 변경하지 않는다.

## 완료 조건

- `npm test`, 수정 JS 구문 검사와 `git diff --check`를 통과한다.
- 실제 브라우저에서 복도 켜짐/소등/복구, 교실/창밖/귀신 얼굴과 토끼 두 표정의 식별을 확인한다. Canvas 강제 호환과 동작 줄이기에서도 색/소등 연결을 확인한다.
- 실제 게임 시작→탐색→토끼 발견→GAME OVER→다시 하기를 확인하고, 일시정지/캡처 고정이 필터와 충돌하지 않는지 확인한다.
- 작업 기록에 참고 해석/적용 내용, 자동 테스트와 실제 브라우저 결과, 모니터·기기별 미확인 사항을 구분한다.
