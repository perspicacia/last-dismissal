# 학생 인형 찌그러짐: 확인된 구조와 다음 단계 제안

2026-10-02 사용자 요청의 진단 기록이다. 처음 음향 수정에서는 제안만 작성했다. 이후 사용자가 3-2 한 개의 정적 GLB 전환을 채택했고 [specs/student-doll-glb.md](../specs/student-doll-glb.md), Issue #60으로 구현했다. 아래는 전환 전의 진단과 단계별 범위 기록이다.

최신 결정: GLB 시안이 기존 인형과 너무 다르다는 피드백으로 일반 게임 기본 적용을 해제했다. [원본 외형 우선 명세](../specs/student-doll-original-look.md), Issue #64에 따라 원본 표현을 복구하고 시안을 비교용으로 보존한다. 2026-10-06에는 [원본 입체 보완 명세](../specs/character-original-depth.md), Issue #91로 머리·몸의 깊이와 곡면 연결을 개선했다. 아래 진단에서 지적한 단일 사진의 측면/후면 정보 부족은 여전히 남는다.

## 코드에서 확인한 사실

- `doll-volume.js`는 정면 PNG의 알파 윤곽·XY 좌표·UV에 앞뒤 깊이를 붙인다. 최초 최대 14cm 균일 깊이에서 현재는 머리 약 26cm·몸·팔다리의 서로 다른 둥근 깊이로 바뀌었다. 원본 눈/얼굴/옷의 사진 투영은 유지한다.
- 머리 앞뒤에 둥근 부피와 얕은 얼굴 굴곡을 부여했지만 독립적으로 조형한 코/입/귀와 실제 측면/후면의 머리 컬·옷 구조는 없다. 옆·뒤는 사진의 행별 평균색으로 채우며 현재 개선을 완전한 3D 조형의 완료로 보지 않는다.
- 따라서 옆으로 보는 각도에서는 사진에 담긴 얼굴/몸이 원근 투영으로 좁아지고 단면이 얇게 보인다. UV/비율 오류와 별개로 2.5D 표현 자체가 가진 한계다.
- 알파 틈·깊은 홈·이미지 미완료 캐시 오류는 이전 PR에서 보완했다. 사용자는 수정 후에도 누운 자세의 찌그러짐을 보고했다. 이번 요청에는 새 인형 화면이 없으므로 현재 재발 부위가 정확히 같은 홈인지, 몸통 두께/시점 문제인지까지는 확인하지 못했다.

## 필요한 기능·자산

1. **실제 3D 인형 메시**: 두개골·얼굴·목·몸통·팔·다리와 옷을 별도 입체 형태로 만든다. Three.js가 읽을 수 있는 GLB/glTF가 적합하다. 정면 사진 한 장만으로 보이지 않는 측면·후면을 정확히 복원할 수는 없으므로 모델링에서 정해야 한다.
2. **모델 전용 UV·재질**: 얼굴·머리카락·옷 텍스처를 각각의 표면에 맞춘다. 현재 전신 사진을 통째로 투영하는 방식은 대체한다. 표면 방향(노멀), 천/도자기의 거칠기와 접촉 그림자를 함께 확인한다.
3. **눕는 자세·배치**: 모델 전체를 같은 비율로 축소하고 머리·등·팔다리가 바닥/책상/의자에 닿도록 회전·높이를 정한다. 지지면 아래로 파묻히는지 확인한다.
4. **추후 관절/표정 전환**: 벌떡 일어나거나 팔을 움직일 때는 관절 리깅과 애니메이션, 표정 변경에는 얼굴 메시/재질 전환 또는 모프 타깃을 추가한다. 현재 학생 인형은 정적 장식이므로 첫 교체에는 리깅이 필수는 아니다.

## 가장 작은 다음 작업

후속 완전 3D 조형은 Blender 등의 모델링 도구에서 원본 금발 컬·도자기 얼굴·유리 눈·세일러복을 맞춘다. 정면 기준에 더해 양옆/뒤 외형을 설계하고 각 부위에 맞춘 UV·색/거칠기/노멀 재질을 제작해 GLB로 내보낸다. 먼저 3-2 바닥 인형 한 개의 정면·양옆·누운 자세를 사용자에게 검토받고 채택 후 3-1 책상에 재사용한다. 현재 음악실 의자는 남자아이 귀신이므로 인형을 다시 배치하지 않는다. 정적 인형에는 리깅이 필수는 아니며 움직이는 고양이 자산에는 관절 골격·보행 애니메이션이 필요하다.

Three.js는 제작한 GLB와 애니메이션을 표시할 수 있으므로 엔진 교체가 필수는 아니다. 필요한 것은 원본과 닮은 조형/텍스처 자산과 브라우저용 최적화다. [Three.js 모델 로딩](https://threejs.org/manual/pages/loading-3d-models.html), [Blender GLB·재질·애니메이션 내보내기](https://docs.blender.org/manual/en/4.3/addons/import_export/scene_gltf2.html)를 참고한다.

Three.js를 계속 사용하며 `assets/models/student-doll.glb`와 로컬 GLTFLoader를 연결했다. 머리·얼굴·금발 단발·옷·팔다리·도자기 관절을 코드로 조형한 3-2 정적 모델이다. 기존 정면 사진의 정확한 재현보다 단순한 외형이며 실제 측면/후면과 누운 자세를 우선한다. 다른 방 교체와 리깅/표정은 후속 범위다. 완료 검증은 [docs/progress.md](progress.md)의 최신 GLB 기록을 참고한다.
