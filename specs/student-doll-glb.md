# 3-2 학생 인형 실제 3D 모델

Issue #60. 사용자가 `docs/student-doll-3d-plan.md`의 가장 작은 교체안을 채택했다.

현재 상태: 외형이 원본과 너무 다르다는 후속 피드백으로 일반 게임의 기본 적용을 해제했다. [원본 외형 우선 명세](student-doll-original-look.md)가 최신 규칙이다. 아래는 보존된 GLB 시안의 제작/검증 기록이다.

## 범위

- 현재 탐색의 3-2 바닥 인형 한 개를 정적 `assets/models/student-doll.glb`로 교체한다.
- 금발 단발, 큰 호박색 유리 눈, 도자기 얼굴·구체 관절, 남색 세일러복·크림 칼라/리본·양말·검은 신발을 유지한다. 원본 정면 사진의 정확한 복원 대신 옆·뒤가 존재하는 입체 외형을 모델링한다.
- 얼굴·뒤통수·머리카락·몸통·옷·팔다리는 실제 입체 메시다. 사진 알파 윤곽에 두께를 붙이거나 전신 사진을 늘리는 방식은 사용하지 않는다. 재질·법선·천/머리 표면 무늬도 모델에 포함한다.
- 누운 정적 자세를 균일 크기로 배치하고 실제 메시 경계에서 바닥 높이를 계산한다. 접촉 그림자를 유지한다.
- 로더는 로컬 vendor 모듈을 사용한다. 로딩 중/실패 및 Canvas 호환에서는 기존 PNG 표시를 유지하고 플레이를 막지 않는다.
- 기존 PNG와 3-1 책상/음악실 의자 인형, 토끼, 창밖 귀신, 판정과 음향은 보존한다. 기존 이상현상 비교 화면의 기립·표정은 이전 렌더를 유지한다.
- 리깅·새 표정·기립 애니메이션과 다른 방의 모델 교체는 후속 작업이다. 추가 캐릭터 이미지 제작 중단을 유지한다.

## 완료 조건

- 실행 시 외부 모델/텍스처 다운로드 없이 GLB 로딩이 완료된다. 모델 자산과 재생성 소스/명령을 저장한다.
- 양옆·머리·발 시점에서 얼굴/뒤통수·머리카락·몸통 두께가 보이며 줄무늬로 늘어진 측면이 없다. 바닥에 파묻히지 않는다.
- 모델의 실제 깊이, 재질/텍스처 포함, 누운 배치·원본 대체를 자동 검사한다.
- 실제 브라우저에서 새 모델과 시작→입장/플레이→토끼 게임 오버→재시작을 확인한다. 소리 출력은 음소거 상태로 유지한다.
- 자동 검증과 플레이/외형 확인 결과, 남은 외형 차이·미확인 사항을 `docs/progress.md`에 기록한다.
