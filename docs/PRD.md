# 마지막 하교 — 목적과 범위

## 목적

익숙한 야간 학교 복도에서 정상 상태를 기억하고 작은 이상을 발견하는 관찰 공포게임을 만든다. 작은 기능 단위로 구현·검증하며 완성도를 높인다.

## 현재 범위

- HTML/CSS/JavaScript와 Three.js로 구현한 브라우저 게임. 기존 Canvas 2D 렌더는 호환 화면으로 유지한다.
- 정상 복도 연습 → 복도 탐색·조사 → 계단 선택 → 반복 → 탈출.
- 물건 수집 없이 이동·관찰로 진행한다. 연습 다음에는 3-2 교실을 선택적으로 탐색하고 복도로 돌아올 수 있다.
- 이상이 있으면 위층, 없으면 아래층. 5회 연속 정답이면 탈출하며 오답은 진행을 0으로 초기화한다.
- 교실·게시판·창문·시계·토끼의 이상현상 5종. 한 복도에 이상현상은 최대 하나다.
- 화살표/WASD 이동·회전, E 조사, 음량·음소거.
- 토끼의 기본·이빨 표정과 창밖 귀신은 게임에 연결되어 있다. 학생 인형 이미지는 게임에 미연결이다.

## 후속 범위

학생 인형 게임 연결, 시야 밖 이동, 추격 AI, 추가 맵은 별도 기능 명세로 정한 후 개발한다. 기존 학생 인형 추가 제작은 중단 상태이며, 이번 요청의 창밖 귀신은 제작·적용했다.
