# 생존 게임 발소리·인형 등장 음향

Issue #42. 플레이어의 걷기 효과음과 잡히는 순간 놀랄 수 있는 짧은 효과음을 추가한다.

- 실제 이동 거리마다 구두/운동화가 목재 바닥을 밟는 둔탁한 발소리와 짧은 마찰음을 재생한다. 회전·정지·벽에 막힌 상태에서는 재생하지 않는다.
- 좌우 발의 음색을 약간 다르게 하고 교실은 복도보다 작게 재생한다. 최소 간격 .18초를 둔다.
- 실패 시 토끼가 나타나는 순간 .85초의 낮은 충격음·금속성 긁힘·거친 잡음을 한 번 재생한다. 기존 접근 경고음과 구분하며 점멸은 추가하지 않는다.
- Web Audio로 합성하고 모든 효과음을 기존 master 음량/음소거로 보낸다. 오디오가 없거나 중단되어도 게임은 진행된다.
- Escape/재시작에서 재생 중 효과음을 중지하고 발 좌우/간격 상태를 초기화한다. 소스 종료 후 연결을 정리한다.
- 검증: 파형 길이·유한 값·피크, 출력 연결·음소거·간격·정리 자동 테스트. 브라우저에서 이동/회전/정지의 호출과 실패 순간 호출, 게임 오버/재시작을 확인한다. 오디오 신호 확인과 실제 청취를 구분한다.
