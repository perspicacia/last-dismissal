# 교실 금발 인형

Issue #28. 사용자 요청으로 기존 학생 인형 이미지를 게임에 연결한다. 추가 이미지 제작은 재개하지 않는다.

- 교실 뒤쪽 중앙 통로 옆 바닥 x-1.05,z6.5에 기존 기본 인형을 눕힌다. 정상/다른 이상에서는 움직이지 않는다.
- 새 doll 이상현상에서는 가까운 1.9m 안에서 인형을 0.3초 바라보면 0.55초 동안 일어난다. 기립 중 크게 벌린 입·날카로운 이빨·세로 동공 표정으로 바뀐다.
- 한 복도에 이상은 하나다. doll 구간은 위층 정답이고 복도 교실 문 유리의 내부 손자국이 단서다. 조사 설명에서도 단서를 확인할 수 있어 교실 방문이 필수는 아니다.
- 기립은 한 번만 발생한다. 교실 복귀·재입장은 상태를 유지하며 새 복도/새 게임은 누운 기본 상태로 초기화한다. 숨긴 탭/중지 시간은 응시로 누적하지 않는다.
- 짧은 관절/불협화음 연출을 쓰되 음소거에서도 표정과 자세로 판별 가능하다. 추격·공격·강제 시점 이동은 없다. 가까이 인형을 볼 때 바닥을 읽을 수 있게 시선을 완만하게 낮춘다.
- 기존 이미지 평면을 기울여 세우는 애니메이션이며 관절이 있는 3D 캐릭터 모델은 아니다. Canvas 호환 화면에서도 자세/표정 차이를 제공한다.
- 완료 조건: 정상 정지, 거리/응시 조건, 중복 방지, 복귀/새 게임 초기화, doll 위층 판정 테스트. 실제 브라우저에서 누움→기립→표정, 문 손자국, 재입장, 시작/엔딩/재시작 흐름 확인.
