# 인형 왜곡·게시판·학교 가구 보완

Issue #36. 사용자 신고 스크린샷의 길어진 인형 턱/얼굴을 수정하고 학교 책상·의자를 참고 사진으로 보완한다.

- 얼굴 중앙의 깊이를 일정하게 유지해 눈·입·턱의 UV 투영이 늘어나지 않게 한다. 머리 외곽·몸체의 두께와 그림자는 유지한다.
- 게시판 사진을 1.05×0.70으로 더 줄이고 중앙 정렬·3:2 비율을 유지한다.
- 책상: 둥근 목재 상판, 금속 다리·보강대, 앞이 열린 수납칸, 고무 발. 의자: 둥근 목재 좌판·작은 등판, 휘어진 금속 등받이 프레임, 보강대·고무 발을 넣는다.
- 기존 가구 위치와 충돌 범위, 인형 기립/표정/초기화와 판정은 유지한다. Canvas 호환 외형은 이번 범위에서 변경하지 않는다.
- 검증: 얼굴 중앙 평탄 깊이 회귀, 사진 비율/크기, 가구 형상 확인, npm test·구문 검사·git diff --check. 실제 브라우저 신고 근거리와 정상/공포 표정, 가구 앞/뒤, 교실 이동·기립·재입장·재시작을 확인한다.
