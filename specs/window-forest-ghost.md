# 창밖 숲과 귀신

- 창밖 정상 풍경은 야간 학교의 나무·숲과 둥근 타원형 조명 머리, 비스듬한 지지대가 있는 가로등으로 구성한다. 창틀은 녹색 금속 프레임과 가로·세로 분할을 강조한다.
- 기존 window 이상현상의 복도 풍경을 창밖 귀신으로 대체한다. 다른 이상현상과 동시 발생하지 않으며 정상 연습에서는 나타나지 않는다.
- 세 번째 캐릭터는 검은 머리, 오래되어 갈라진 도자기 인형 얼굴, 무표정한 검은 눈과 낡은 흰 옷의 오리지널 귀신이다. 기존 학생 인형과 별개의 외형이며 혈흔·상처·점멸·강제 점프스케어는 추가하지 않는다.
- 귀신은 창밖 가로등 근처에 서서 안을 바라본다. 무음에서도 관찰 가능하고 조사 설명과 이상 판정이 일치한다. 교실의 창밖에도 동일한 숲 풍경을 적용한다.
- 시작·새 복도·재시작 시 현재 이상현상에 맞춰 귀신을 표시/제거한다. 기존 이동·교실 탐색·계단 진행·5회 탈출 규칙을 유지한다.
- 검증: npm test, 변경 JS 구문 검사, git diff --check. 정상/귀신 창문 렌더·프레임 가림·초기화 테스트, 브라우저 정상/귀신 및 교실 화면을 확인하고 실제 수행 여부를 기록한다.
