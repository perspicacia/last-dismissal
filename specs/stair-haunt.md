# 계단 아래의 접근 소리 (Issue #82)

사용자가 계단 근처가 비어 보이므로 접근했을 때 놀랄 만한 이상한 소리를 요청했다.

- 일반 탐색의 복도 끝 `z >= 22.1`에 0.3초 머무르면 새 게임당 한 번 발생한다. 양쪽 계단 앞에서 들리고 시선 방향은 조건으로 삼지 않는다. 교실·첫 화면·종료 상태에서는 발생하지 않는다.
- 아래층에서 쇠를 긁는 소리 → 짧은 정적 → 점점 가까워지고 빨라지는 계단 발소리 → 마지막 무거운 발 구름과 짧은 메아리의 약 3.6초 합성음이다. 발생 시 아래층 계단 방향의 좌우 위치를 반영하며 지원하지 않는 오디오 환경에서는 같은 소리를 중앙에서 재생한다.
- 공포 분위기 요소이며 새 공격자/패배/방문 조건을 추가하지 않는다. 어지러움 완화 설정을 유지하고 카메라 이동·흔들림·새 점멸을 넣지 않는다. 추가 캐릭터 이미지도 제작하지 않는다.
- 전체 음량/음소거를 따른다. 음소거 중에도 이벤트를 소비해 해제 시 밀린 소리가 나지 않는다. 일시정지·방 진입·종료·처음 화면에서는 재생 중인 소리를 정리한다. 재개/재방문에는 다시 놀라게 하지 않으며 새 게임은 초기화한다. 발생 전 일시정지에는 대기 시간을 동결한다.
- 기존 일반 합성음 규칙과 로컬 문/토끼 녹음을 보존한다. 시간 지연은 단일 PCM 버퍼 안에 들어가므로 취소 뒤 별도의 발소리 타이머가 남지 않는다.

## 완료 조건

접근 영역/체류/단발/음소거 소비/방 이동/프레임 제한/재시작과 파형의 발소리 간격·피크·정적·메아리, master/좌우 출력·캐시·재생 중 취소를 자동 검증한다. 실제 브라우저에서 복도 접근/발생/멀어졌다 재접근/음소거 접근/교실 이동/일시정지/토끼 종료/재시작을 확인한다. 장치 청감 확인과 출력 없는 호출 검증을 구분해 기록한다.
