# 개발 Agent A — 열쇠·문과 쉬운 조작

- 작업 브랜치: `codex/key-door` (분리 워크트리).
- `specs/key-door.md`에 따라 첫 정상 연습만 열쇠·방화문 적용.
- 오른쪽 4m 책상, 8m 방화문. 열쇠 3.2m 접근 시 조준 없이 E/큰 버튼으로 획득.
- 보유·목표 표시, 문 앞 책상 안내, 키 없이 개방 방지, 문이 닫힌 동안 7.5m에서 이동 차단.
- 연습 종료 후 절차 생략, 새 시작·엔딩 재시작 시 키와 문 초기화.
- 임시 Canvas 책상·금빛 열쇠·불투명 방화문 그래픽. 토끼/학생 기존 이미지 보존.
- 짧은 키 입력 이동도 기존 발소리 거리 누적에 포함.
- B의 `horror-events.js`/`SchoolAudio.cue()` API를 게임에 연결. 성공한 획득·문 개방·토끼 표정 이벤트만 호출하며 새 복도에서 게이트 초기화.

## 검증

- `npm test`: 기존 7개 + 신규 4개 = 11개 통과.
- `node --check game.js`, `node --check corridor.js`: 통과.
- `git diff --check`: 통과.
- UI/UX skill의 명시 버튼·상태 피드백·키보드/터치 동등 조작 기준 적용.
- 브라우저 실제 플레이와 시작 → 종료 → 재시작은 통합 담당 root가 검증한다. 이 워크트리에서는 미확인.
- B 파일은 다른 워크트리에서 제작되어 이 커밋 단독 게임 실행은 불가하다. 통합 때 반드시 함께 반영한다.
