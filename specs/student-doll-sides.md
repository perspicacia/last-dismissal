# 학생 인형 측면 왜곡·이미지 로딩 순서 수정 (Issue #56)

기존 사진 실루엣에 두께를 붙인 인형은 낮은 측면에서 머리카락 아래가 기둥처럼 보이고 얼굴이 눌려 보인다. 바닥·책상·피아노 의자에 있는 학생 인형을 모두 수정한다.

- 확정된 금발 단발, 유리 눈, 남색 세일러복과 기존 PNG를 보존한다. 새 캐릭터 이미지 제작은 하지 않는다.
- 머리카락 사이의 미세한 알파 틈을 기하 형태에서만 메운다. 원본 PNG·UV·XY 비율은 보존하고 알파는 앞면에서 계속 사용한다. 틈이 깊은 3D 홈으로 늘어나지 않게 한다.
- 앞뒤 표면을 완만한 곡면으로 연결한다. 윤곽의 봉합선은 2mm 이하를 유지하고 UV의 가로·세로 배율을 변경하지 않는다. 이전 평평한 사진 앞면과 과하게 두꺼운 뒷면의 경계를 대체한다.
- 뒤·옆의 색을 각 행의 불투명 픽셀 평균으로 부드럽게 구성한다. 머리카락·옷 주름의 세부 무늬가 아래로 반복되어 기둥처럼 보이지 않게 한다. 두께 상한을 18cm에서 14cm로 줄인다(1.55m 기준, 작은 인형도 균일 축소).
- 배치·공포 판정·표정 전환을 유지한다. 모든 부분을 같은 비율로 축소하고 지지면 아래로 파묻히지 않게 한다.
- 이미지 크기만 알려지고 PNG가 미완료일 때는 형상을 만들지 않는다. 빈 알파로 생성된 지오메트리를 완료 상태로 저장하지 않고 onload 때 다시 시도한다. 미완료 텍스처·토끼 분할 캐시에도 같은 로딩 완료 조건을 적용한다.

완료 조건: `npm test`, `git diff --check`. 브라우저에서 3-2 바닥, 3-1 책상, 음악실 의자의 인형을 정면·왼쪽·오른쪽·근접 시점에서 확인한다. 입장·복귀·토끼 게임 오버·재시작도 확인한다. 테스트 통과와 실제 화면 확인은 구분해 기록한다.

단일 정면 사진을 사용하는 2.5D 구조는 유지한다. 완전한 후면·측면 얼굴과 관절형 3D 캐릭터 제작은 이 오류 수정의 범위가 아니다.
