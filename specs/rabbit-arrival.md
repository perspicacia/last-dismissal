# 토끼 등장·비명 보완

- Issue #46. 기존 숨은 교실 토끼 발견·즉시 패배 판정은 유지한다.
- 발견 직후 .3초 동안 기존 기본 표정으로 보인다. 이어 .7초 동안 플레이어 쪽으로 다가온다. 발견 후 .55초에 이빨 표정으로 전환하고 비명 효과음을 한 번 낸다. 1.5초에 게임 오버 화면으로 전환한다.
- 토끼 폭/높이는 표시 중인 원본 이미지의 naturalWidth/naturalHeight 비율을 유지한다. 원본 PNG나 새로운 캐릭터 이미지는 제작·수정하지 않는다.
- Three.js와 Canvas 모두 같은 시간·표정·비율 규칙을 따른다. 동작 줄이기에서는 이동/확대만 생략하고 표정 전환·효과음 시점은 유지한다.
- 비명은 외부 음원 없이 음성 대역과 거친 호흡을 합성한다. 기존 음량·음소거·종료 정리를 적용한다. 단순 고주파 삑 소리보다 ‘우아악’ 같은 하강하는 목소리 질감을 목표로 한다.
- 팔 동작은 [rabbit-raised-arms.md](rabbit-raised-arms.md)의 만세 자세를 적용한다.
- Escape/재시작은 비명 예약/재생과 표정 상태를 초기화한다.

## 검증
`npm test`, `git diff --check`. 원본/비정방형 이미지 비율, 기본→이빨 시점, 단일 효과음·음소거·재시작을 자동 검증한다. 브라우저에서 기본/공포 표정 렌더와 시작→발견→게임 오버→재시작을 확인한다. 음향 신호 검증과 실제 귀로 듣는 체감은 구분한다.
