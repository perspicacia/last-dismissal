# 통합 검토 기록

- 검토 Agent는 코드를 수정하지 않고 재시작·진행 불가·기능 충돌을 검토했다. 전체 테스트와 순수 이동·판정 재현을 수행했다.
- P2 발견: 열쇠 미보유 상태 `(x:2,z:6)`에서 E를 누르면 열쇠까지 2m인데 `locked`로 판정됐다. 기대는 3.2m 범위의 열쇠 획득이다. 뒤로 이동하면 해결되어 진행 불가는 아니었다.
- 개발 A 수정: 열쇠 거리 검사 우선 적용, 겹침 위치와 경계 회귀 테스트 추가. 통합 후 전체 16개 테스트 통과.
- 닫힌 문 z=7.5 차단 → 뒤로 이동해 획득 → 문 개방 → 계단 도달, 연습 종료 후 절차 생략, 정답 5회 탈출, 새 게임 초기화를 순수 모듈로 확인했다.
- 음소거 master 연결, 효과음 중복 방지와 reset, 엔딩 음향 감쇠 예약 초기화 테스트 통과. 새로운 진행 불가 조건은 발견하지 못했다.
- root 브라우저 검증: 클릭/E 획득과 문 개방을 양쪽 조합으로 확인했다. 실제 복도 조사와 계단 선택으로 5회 연속 정답 탈출, 엔딩 재시작, 처음 화면 재시작, 음소거 중 퍼즐 진행을 확인했다. 콘솔 오류·경고 없음.
- 미확인: 하드웨어에서 들리는 소리·공포 강도, 모바일 실기기. 알려진 기존 조작/표시 항목은 `docs/progress.md`를 참고한다.
