# 교실 창밖 운동장 전경

- Issue #24. 교실은 복도의 숲길과 다른 방향의 운동장을 바라본다.
- 창마다 반복 타일을 쓰지 않고 창 전체 길이 1.8~8.9m를 하나의 파노라마에 연결한다.
- 창틀은 유지하고 운동장, 농구대, 골대, 외곽 숲, 가로등은 서로 다른 위치에 놓는다.
- 정상 기준 풍경은 반복 방문해도 고정된다. 교실에는 귀신을 추가하지 않는다.
- 복도 창밖 귀신, 이동·이상 판정·출입 조작은 유지한다.
- 완료 조건: 실제 렌더에서 풍경 연속성과 회전 시 창 위치 고정, 교실 복귀 확인, npm test 통과.
