# 수집 없는 관찰 진행

- 이 명세는 기존 열쇠·문, 교실 확인표, 걷는 계단 명세의 필수 수집 조건을 대체한다.
- 첫 정상 연습 복도부터 열쇠 획득과 문 해금 없이 끝까지 걸을 수 있다. 열쇠·잠긴 방화문·수집 버튼을 표시하지 않는다.
- 교실 확인표와 보유 상태를 제거한다. 정규 복도의 교실은 선택 탐색이며 방문 여부가 계단 진입에 영향을 주지 않는다.
- 연습은 아래층 입구로 진행하고, 이후 이상이 있으면 위층/없으면 아래층으로 이동한다. 오답 초기화와 5회 연속 정답 탈출을 유지한다.
- 조사·교실 입장/복귀·사운드는 유지한다. 시작 안내도 수집 없이 관찰하는 흐름으로 수정한다.
- 검증: npm test, JavaScript 구문 검사, git diff --check. 브라우저에서 수집 없이 연습 완료·정규 계단 진입·교실 입장/복귀·종료·재시작을 확인하고 미확인 항목을 기록한다.
