# 가면 얼굴의 교복 여고생 귀신

범위: [Issue #113](https://github.com/perspicacia/last-dismissal/issues/113).

2026-10-06 사용자 채택: 현재 공격자의 얼굴이 너무 아름답다는 피드백과 새 참고 이미지에 따라 외형을 하얀 가면 같은 얼굴·가늘고 무표정한 눈·남색 세일러 교복으로 바꾼다. 기존 여고생 공격자의 디자인 수정과 신규 두 표정 자산 제작/적용은 이번 사용자 요청 범위다. 다른 캐릭터의 신규 이미지 제작 중단은 유지한다.

## 외형

- 독자적인 가상의 인물이며 참고 이미지의 인물/배경을 그대로 복사하지 않는다. 인형/가면처럼 창백하고 납작한 표정, 가는 검은 눈, 작고 어두운 붉은 입술, 검은 긴 생머리와 노출된 귀를 사용한다. 미인형 얼굴·큰 반짝이는 눈·매력적인 화장·모델 같은 표정을 피한다.
- 낡은 남색 긴 소매 세일러복, 흰색 목깃 줄무늬, 어두운 붉은 리본과 남색 주름치마, 어두운 양말과 신발을 사용한다. 현재 전신 정면/팔이 내려간 자세와 비율을 유지한다.
- 기본 얼굴은 무표정이다. 공격 표정은 같은 인물/몸/의상/프레이밍에서 얼굴만 검은 입과 눈 주변의 불길한 표정으로 바꾼다. 과도한 유혈/발광/만화 같은 직사각형 이빨을 추가하지 않는다.
- 실제 투명 배경 PNG 두 장을 별도 이름으로 저장한다. 기존 여고생/토끼와 기타 캐릭터 PNG는 보존한다. 생성/편집 프롬프트와 사용 도구를 자산 문서에 기록한다.

## 적용과 유지

- 일반 Three.js·Canvas, 첫 화면·게임 오버와 비교 화면에서 새 기본/공격 자산을 공유한다. 실제 관절 3D 모델로 보고하지 않는다.
- 다섯 방 중 한 곳 무작위 배치, 시작 숨김, 기존 발견 시야/거리·1.5초 종료·.55초 공격 표정/비명·GAME OVER/다시 하기, 로딩 실패/재시도/음소거와 접근성·조명은 유지한다. 토끼 피 얼룩·팔 분할을 적용하지 않는다.
- 정면 전신과 얼굴 확대에서 가면 같은 얼굴/남색 교복이 읽히고, 표정 교체 시 몸/의상이 흔들리지 않는지 확인한다. 밝은 비교와 실제 어두운 게임 조명 모두에서 확인한다.

## 완료 조건

- 두 자산의 크기/실제 alpha·정렬/색·프레이밍 확인, 기존 자산 보존.
- 관련 회귀 및 전체 테스트와 실제 브라우저의 첫 화면→시작→발견→돌진→GAME OVER→다시 하기 확인. 자동 테스트와 실제 플레이·체감 외형 평가를 구분한다.
- `docs/progress.md`에 변경/검증/미확인 사항과 다음 작은 작업을 남기고 별도 브랜치에서 검토용 PR을 만든다.
