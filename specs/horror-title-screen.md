# 공포 포스터형 첫 화면 (Issue #68)

## 사용자 채택 방향

첨부한 어두운 공포 웹툰 표지를 참고한다. 현재 등장하는 귀신들을 메인에 모아 보여주고 어두운 배경과 거친 제목 서체를 적용한다. 영문 게임명만 남기는 기존 방향을 유지한다.

## 구현 범위

- 토끼(`mascot-rabbit-open.png`), 금발 학생 인형(`doll-student-open-slit-eyes.png`), 긴 머리 귀신(`window-ghost.png`), 남자아이(`piano-boy-ghost.png`)의 기존 투명 이미지를 재배치한다. 구석 그림자는 학교 배경의 작은 실루엣으로 포함한다. 기존 인물 이미지를 다시 생성하거나 변경하지 않는다.
- 후속 [얼굴 없는 학생 명세](faceless-student-upgrade.md)에서 승인한 신규 학생(`faceless-student.png`)을 배경 쪽에 더해 다섯 얼굴이 구분되게 한다. 세로 화면은 학생을 기존 인형과 긴 머리 귀신 사이에 둔다.
- 검정/먹색 학교 배경과 붉은 역광·안개·잉크/스크래치로 하나의 포스터 구도를 만든다. 주요 얼굴은 제목 위에서 구분되도록 두고, 겹치는 몸/다리는 어둠 속에 자연스럽게 숨긴다.
- 영문 `LAST DISMISSAL`을 거친 페인트/붓질 느낌의 로컬 서체와 밝은 글자·붉은 음영으로 표현한다. 참고 표지의 인물·한글 제목·로고는 복제하지 않는다. 폰트 출처와 라이선스를 자산 폴더에 보관한다.
- 제목, 학교에 들어가기 버튼, 기존 음소거/음량만 표시한다. 캐릭터 이름표, 서사/규칙/개발 설명을 추가하지 않는다. 장식 이미지는 접근성 트리에서 숨기고 제목은 실제 H1로 유지한다.
- 첫 화면에만 배경/헤더/타이포그래피 스타일을 적용한다. 게임 오버/탈출 화면의 원래 레이아웃, 플레이 상태·음향·방문/공격 판정은 유지한다.
- 모바일과 낮은 가로 화면에서는 얼굴/제목/시작 버튼을 다시 배치하고 가로 넘침을 막는다. 조작 영역은 최소 44px이며 키보드 포커스를 눈에 보이게 유지한다. 점멸이나 자동 포스터 이동은 추가하지 않는다.

## 검증

- `npm test`, `git diff --check`.
- 실제 브라우저 데스크톱/모바일/가로 화면의 캐릭터 구분, 제목/버튼 가독성, 이미지/폰트 로딩과 가로 넘침 확인.
- 키보드 시작 → 플레이 → 토끼 발견/게임 오버 → 재시작 → Escape 첫 화면 복귀 확인. 소리 출력 없는 검증과 실제 청감을 구분한다.
- 사용자 체감 공포 강도와 최종 외형 채택, 실제 모바일 기기 성능은 미확인 사항으로 기록한다.
