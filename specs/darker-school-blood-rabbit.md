# 어두운 학교와 피 얼룩 토끼 (Issue #93)

- 사용자 요청: 전체 배경 밝기를 더 낮추고 최종 공격자인 토끼 얼굴에 피가 번진 외형을 적용한다.
- 기존 캐릭터 입체 보완 브랜치 `codex/character-original-depth`를 바탕으로 별도 개발한다. 원본 PNG와 다른 캐릭터의 외형은 보존한다.
- 실내 노출, 주변광, 달빛과 천장등 광량을 함께 낮춘다. 문 이름표, 바닥 경계, 책상과 창밖 숲/가로등은 구분할 수 있어야 한다. 복도 소등 주기/복구, 중단/재시작, 동작 줄이기 규칙은 유지한다.
- Canvas 호환 화면도 기본 암부를 더 깊게 한다. 별도의 캐릭터 비교 화면의 검토용 조명은 변경하지 않는다.
- 토끼의 원본 두 표정에 동일한 위치의 어두운 적색 번짐/흐르는 자국/작은 튄 얼룩을 코드 기반으로 겹친다. 눈동자/코/이빨의 윤곽, 귀/팔/몸 비율은 보존한다. 색만 칠해 털 무늬를 없애지 않으며 원본의 투명도와 실루엣을 유지한다.
- 표정 변경 때 얼룩이 튀거나 사라지지 않도록 같은 좌표와 결정적인 질감을 공유한다. 이미지가 늦게 로드되면 로드 후 생성하고 재시작마다 재생성하지 않는다. 일반 Three.js, Canvas 돌진, 첫 화면 토끼에 같은 외형을 연결한다.
- 발견/무표정→이빨/돌진/만세 시간, 비명, 게임 오버와 다시 하기 판정은 변경하지 않는다. 신규 공격자나 조작은 추가하지 않는다.

## 완료 조건

- 전체 테스트와 `git diff --check`를 통과한다.
- 실제 브라우저에서 복도 켜짐/소등/복구, 교실/창밖, 두 토끼 표정과 돌진 근접을 확인한다. Canvas 호환 및 동작 줄이기도 확인한다.
- 시작→교실 탐색→토끼 발견→GAME OVER→다시 하기 흐름을 실제 컨트롤러에서 확인한다. 자동 테스트와 브라우저 확인, 미확인 기기/음향 사항을 구분해 기록한다.
