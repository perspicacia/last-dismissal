# 학교 공간과 시계의 입체감

- 참고 시계의 짙은 갈색 두꺼운 원형 테두리, 흰 문자판, 큰 1–12 숫자, 꽃 장식과 장식 바늘을 Canvas로 구현한다. 정상 시각은 23:17, 이상에서는 두 바늘이 아래를 향한다. 시계의 원형 비율과 벽에서 돌출된 두께·그림자를 표현한다.
- 복도 창틀·문틀·게시판 가장자리와 형광등에 실제 세계 좌표의 두께, 옆면·밑면·접촉 그림자를 더한다. 교실의 기존 가구와 창문에도 깊이 표현을 적용한다.
- 창밖 숲은 먼 숲/중간 나무/가까운 나무의 크기·색·대비를 구분하고 이동 시 거리별 시차를 준다. 가로등 주변 길과 빛도 원근에 맞춘다. 귀신은 기존 이상현상 위치·판정을 유지한다.
- 새 수집·선택 UI나 진행 규칙 변경은 하지 않는다. 렌더링만 변경한다.
- 병렬 범위: 외부 풍경 Agent는 별도 워크트리의 window-view.js와 관련 테스트만 수정한다. 주 작업자는 시계·복도·교실 렌더와 통합을 맡는다.
- 검증: npm test, 변경 JS 구문 검사, git diff --check. 브라우저에서 시계 정상/이상, 원형 비율, 근거리/회전 두께, 창밖 시차와 교실, 시작·계단·재시작을 확인한다. 미확인 항목은 진행 문서에 기록한다.
