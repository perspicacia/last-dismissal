# 마지막 하교

부트캠프 과제용 관찰 공포게임. 목표는 짧은 플레이로 규칙과 분위기를 전달하는 것이다.

## 실행

프로젝트 폴더에서 `npm start` 또는 `python3 -m http.server 8080 --bind 127.0.0.1`을 실행하고 브라우저에서 http://127.0.0.1:8080 을 연다. 설치할 패키지는 없다. HTML 파일을 직접 열면 ES 모듈 제한 때문에 실행되지 않을 수 있으므로 로컬 서버를 사용한다.

- 일반 플레이: 무작위 정상/이상 복도. 직접 걸어가 가까운 사물을 조사한다.
- ↑↓는 앞뒤 이동, ←→는 방향 회전. WASD도 같은 방식으로 조작할 수 있다. 누르고 있으면 연속 이동한다.
- E는 바라보는 가까운 사물 조사. 화면의 이동 버튼은 누르고 있는 동안 이동하며 키보드 Enter로도 한 걸음씩 조작할 수 있다.
- 복도 끝(22m 이상)에 도착하면 위층/아래층 계단 선택 버튼이 활성화된다. 선택 후 다시 복도 입구에서 시작한다.
- 음량 슬라이더에 포커스가 있으면 화살표는 음량을 조절한다. 복도 화면을 클릭하면 이동 조작으로 돌아온다.
- `npm test`: 정답 누적, 오답 초기화, 무작위 현상 선택, 이동·충돌·조사 거리, 토끼 표정 전환 조건을 검사한다.

## 파일 구성

`index.html`은 화면, `style.css`는 화면 스타일, `logic.js`는 판정과 현상 선택, `game.js`는 조사와 화면 상태, `audio.js`는 합성 음향, `movement.js`는 이동·충돌·조사 거리, `corridor.js`는 Canvas 기반 1인칭 복도 렌더링을 담당한다. 현상을 늘릴 때 `logic.js`의 목록, `game.js`의 조사 문구, `corridor.js`의 그림 상태를 함께 수정한다.

## 첫 버전 기획

- 배경: 야간 학교 복도. 과제를 끝낸 학생이 같은 복도에 갇힌다.
- 기본 규칙: 이상이 있으면 올라가고, 없으면 내려간다.
- 첫 복도는 정상 상태를 익히는 연습 공간이다.
- 정답 5회 연속으로 하교. 오답은 진행을 0으로 되돌린다.
- 이상현상은 한 번에 하나만 나온다. 애매한 장식 변화는 판정에 쓰지 않는다.
- 정상 복도에도 약한 환경음이 있다. 음악 자체는 정답 힌트가 되지 않는다.
- 시작 버튼과 재시작 버튼은 모두 무작위 일반 플레이로 진입한다.

## 음향 기획

큰 소리로 놀라게 하기보다, 익숙한 공간이 낯설어지는 분위기를 만든다.

1. 시작 화면: 무음. 사용자가 시작 버튼을 누른 뒤에만 오디오를 켠다.
2. 복도: 낮은 드론과 형광등 소리. 드론은 작게 유지하고 장시간 들어도 부담이 적도록 한다.
3. 조사: 필요한 사물에 접근하거나 조사할 때 짧은 소리. 시각적인 단서도 함께 제공한다.
4. 계단 선택: 짧은 전환음. 오답은 불협화음, 정답은 작은 종소리.
5. 탈출: 긴장음을 낮추고 새벽 분위기의 화음을 낸다.

초기 버전은 Web Audio로 직접 합성한 음향을 사용한다. 외부 음악 파일이나 다운로드가 필요하지 않다. 이후 실제 음원으로 교체할 때 출처와 이용 조건을 기록한다. 음소거와 음량 조절을 제공하고, 소리가 없어도 판정 가능하도록 설계한다.

노트북 스피커에서도 들리도록 196~349Hz의 드론과 24초 반복 선율을 함께 사용한다. 기본 음량은 50%다. 상단의 ‘소리 확인’은 오디오를 다시 시작하고 확인용 종소리를 재생한다. 시작 전에는 음악이 재생되지 않으며, ‘소리 확인’을 누르면 시작 화면에서도 들을 수 있다. ‘BGM 재생 중’은 브라우저의 오디오 실행 상태를 뜻하며, 기기나 브라우저 자체의 음소거 여부까지 확인하지는 않는다.

## 범위와 이후 개선

현재 버전은 화살표로 걷고 둘러보는 1인칭 복도 탐색 게임이다. 벽을 통과하지 못하며 가까이에서 바라보는 사물만 조사할 수 있다. 외부 3D 엔진 없이 Canvas 레이캐스팅으로 공간을 표현한다. 적 AI와 추가 맵은 후속 범위다. 후속 개선에서는 새 기능을 추가하기 전에 플레이어가 정상 상태와 이상 상태를 구별할 수 있는지 확인한다.

## 토끼의 두 얼굴

정상 토끼는 입을 닫은 모습이다. 토끼 이상현상에서는 복도 중간으로 옮겨진 토끼를 4.2m 안에서 바라보면 날카로운 이빨을 드러낸다. 한 번 드러낸 얼굴은 해당 복도가 끝날 때까지 유지되고, 새 복도에서는 초기화된다. 두 장의 투명 PNG를 교체하는 연출이며, 턱이 연속적으로 움직이는 3D 애니메이션은 아니다.
