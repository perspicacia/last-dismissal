# 낡고 얼굴이 지워진 게시판 사진

관련 [Issue #99](https://github.com/perspicacia/last-dismissal/issues/99).

사용자가 칠판의 사진을 얼굴이 까맣게 칠해진 초안으로 바꾸고 낡은 느낌을 요청했다. 현재 사진이 배치된 복도 게시판에 적용한다. 이 명세는 일반 탐색 게임의 사진 선택에 한해 [기존 게시판 사진](board-photo.md)의 정상 사진 규칙을 대체한다.

- 일반 탐색 게임은 기존 `assets/school-group-photo-erased.png`를 사용한다. 열 명의 검게 지운 얼굴은 그대로 구분되게 유지한다.
- 누런 인화지, 바랜 색, 모서리 얼룩, 얇은 긁힘/접힌 자국과 닳은 테두리를 코드 기반 Canvas 질감으로 만든다. 원본 PNG 두 파일은 수정하지 않는다.
- Three.js와 Canvas 호환 화면은 같은 사진 선택과 낡은 질감을 공유한다. 완료된 이미지에만 한 번 생성하고 캐시하며 사진 로딩 중에는 정상 얼굴 사진을 대신 표시하지 않는다.
- 게시판/사진 위치, 1.05×0.70m 크기와 3:2 비율을 보존한다. 글씨나 새 라벨을 추가하지 않는다.
- 기존 관찰 모드/개발 비교의 정상 사진과 게시판 이상 사진은 구분을 유지한다. 현재 탐색 게임의 방문·토끼 공격·종료·재시작·음향·조작·조도는 변경하지 않는다. 장식의 난수는 게임 난수를 소비하지 않는다.

완료 조건: 일반 게임의 낡은 검은 얼굴 사진을 실제 Three.js/Canvas 브라우저에서 확인하고, 이전 정상/이상 비교를 보존한다. 기존 전체 테스트·구문·diff 검사를 통과하며 진행 기록과 검토용 PR을 남긴다.
