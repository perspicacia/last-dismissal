# 학교 3D 품질 보완

2026-10-06 사용자 요청: 진단한 공간 재질·조명·충돌·성능과 원본 기준 캐릭터 제작 경로를 보완한다.

관련 [Issue #117](https://github.com/perspicacia/last-dismissal/issues/117). 기준 브랜치는 `codex/restore-rabbit-presence`, 작업 브랜치는 `codex/3d-quality-foundation`이다.

## 구현 범위

- 복도/교실 벽·목재·금속에 서로 독립된 색/표면 노멀/거칠기 맵을 결정적으로 생성하고 공유한다. 근접 마모·목재 결·이음부와 금속의 표면 차이를 추가한다. 게임 난수와 캐릭터 PNG는 변경하지 않는다.
- 천장등의 위치와 맞는 제한된 실내 그림자 광원으로 가구의 접촉과 높이를 표현한다. 같은 기존 전등 소등 신호를 따른다. 주요 등만 그림자를 계산하고 나머지는 기존 점광원이다. 방향광 범위를 실내에 맞추며 문/바닥/얼굴 식별·현재 학교 색감·동작 줄이기/캡처를 유지한다.
- 렌더와 이동이 같은 복도 책상 치수를 사용하며 정면/옆걸음/대각선 충돌과 벽을 따라 미끄러지는 이동을 검증한다.
- 표정/방 이동 때 기존 텍스처를 다시 만드는 대신 이미지별 캐시를 재사용하며 재시작에서 교체되는 시계 캔버스는 해제한다. 정적인 반복 책상/의자는 같은 치수·좌석 회전을 유지하는 인스턴싱을 적용한다. 개발 비교 화면에 실제 렌더 호출/삼각형/텍스처·geometry 개수와 CPU 제출/프레임 간격 측정을 제공한다. 개수를 GPU 메모리 바이트로 보고하지 않고 장치별 성능을 측정 없이 확정하지 않는다.
- 2026-10-06 후속 지속 보완 요청: 첫 화면의 비활성 시간에 `compileAsync`로 복도부터 방별 셰이더를 하나씩 준비한다. 플레이·일시정지·캡처·숨김 탭에서는 새 준비 작업을 시작하지 않는다. 이미 시작한 컴파일을 기다려 시작 버튼을 막지 않으며 장면을 실제로 그리거나 게임 난수·이동·공포 시계를 진행하지 않는다. 늦게 로딩되는 이미지/몸통에 맞춰 필요한 준비를 갱신하고 실패 시 일반 렌더를 유지한다. 개발 비교에서 사전 준비 켜짐/꺼짐의 첫 CPU 제출 시간을 같은 조건으로 기록한다. 텍스처 업로드·그림자 깊이 패스·모든 장치의 첫 프레임 지연까지 해결했다고 보고하지 않는다.
- 원본 인형을 기준으로 별도 닫힌 머리/몸/의상/사지 메시·뼈/웨이트·검토용 동작을 갖는 모델 후보를 만든다. 정면 사진을 재사용하고 옆/뒤는 근사라는 한계를 표시한다. 기존 시안/PNG는 보존한다. 완전한 전 방향 원본 복원으로 보고하지 않는다.
- GLB 로딩은 검토 모델의 전체 스킨 계층/재질/클립을 보존하고 독립 인스턴스를 만든다. 밝은 원본 비교·정면/사선/뒤/관절 동작과 실제 학교 조명을 검토할 수 있게 한다. 일반 게임 인형은 최신 원본 외형 유지 규칙에 따라 바꾸지 않으며 모델 후보를 검토 후 채택한다.
- 새 캐릭터 그림/구매/설치/엔진 교체/배포는 범위 밖이다. 현재 여고생만 공격하고 토끼는 3-1 비공격 캐릭터다. 발견/표정/비명/종료/재시작·카메라·음향·기존 배치는 보존한다.

## 완료 조건

- 재질 맵/결정적 생성·광원 그림자/소등 연결·텍스처 동일성·충돌·모델 스킨/클립/인스턴스/실패 재시도 검증, 전체 `npm test`, `git diff --check`.
- 셰이더 준비 큐의 단일 실행·중복 합치기·로딩 중 변경·플레이 중 중단/첫 화면 복귀·실패 대체를 검증한다. 실제 브라우저에서 준비 상태와 첫 제출 시간 및 시작→플레이→종료→재시작을 확인한다.
- 실제 브라우저에서 복도/교실/음악실의 표면·그림자와 밝은 모델 비교를 확인한다. 시작→방 탐색→GAME OVER→재시작, 일시정지/캡처·Canvas 호환을 확인한다. 실제 프레임/렌더 측정은 조건과 함께 기록한다.
- 사용자 Mac 동시 조작 시 입력을 중단하고 별도 검증 탭을 사용한다. 자동 테스트와 실제 플레이·미확인 외형 채택/기기 범위를 구분한다.
- `docs/progress.md`, README, 자산 출처/재생성 방법과 검토 PR을 갱신한다. 리뷰 후 main 병합/통합 검증, 배포는 요청 시 진행한다.
